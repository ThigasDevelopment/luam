# 5.3 — Build VS Code extension and syntax highlighting

> File: `.claude/plans/5.3-vscode-extension-architecture-engineer.md`

## Objective

Deliver a VS Code extension that starts the LSP, registers the language id,
and provides TextMate syntax highlighting.

## Scope

- **In:** Extension manifest, language id registration, LSP client launch,
  TextMate grammar, keybindings/commands for `ensure`.
- **Out:** Other editor integrations.

## Steps

- [x] Create `packages/vscode` with extension manifest.
- [x] Register the language id `luam` and the `.luam` file extension
      ([ADR-002](../docs/adr/002-luam-source-file-extension.md)).
- [x] Launch the LSP client from the extension.
- [x] Add a TextMate grammar for the source language.
- [x] Add a command that runs `ensure`.

## Acceptance Criteria

- [x] Extension activates on source files.
- [x] Diagnostics and completion work through the LSP.
- [x] Syntax highlighting covers key constructs.
- [x] The `ensure` command is available.
