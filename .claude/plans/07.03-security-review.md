# 07.03 - Review generated code and runtime security

> File: `.claude/plans/07.03-security-review.md`

## Objective

Audit generated Lua and runtime helpers for injection risks, unsafe
metamethod use, and secret exposure, and fix findings.

## Scope

- **In:** Template string safety, table/string extension safety, runtime
  helper audit, generated code review, secret handling in CLI config.
- **Out:** Sandboxing or anti-cheat guarantees beyond MTA defaults.

## Steps

- [x] Review template string lowering for context and injection safety.
- [x] Audit runtime helpers for blocked metamethods and unsafe patterns.
- [x] Review CLI config handling for secrets (RCON password).
- [x] Document findings and apply fixes.

## Acceptance Criteria

- [x] Findings are documented with severity.
- [x] Applied fixes are covered by tests.
- [x] Secrets are not logged or committed.
