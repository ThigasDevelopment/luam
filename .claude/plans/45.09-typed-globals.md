# 45.09 - Type a global the source assigns later

> File: `.claude/plans/45.09-typed-globals.md`

## Objective

Give a resource a way to declare a global that is filled in later, so the
universal "declare at the top, assign when the event fires" shape stops being a
type error with no legal spelling.

## Reproduction

```luam
network = nil

addEventHandler('onClientResourceStart', resourceRoot, function ()
    network = new Network({ event = 'sync' })
    # check-type-mismatch: Assignment expects "nil" but received "Network".
end)
```

The first assignment types the global exactly `nil`, and every later assignment
fails against it. The annotation that would fix it does not parse:

```luam
network: Network = nil
# parse-unexpected-token: Expected "(" but found "=".
```

`declare network: Network` is rejected outside a `.d.luam` file, and a `.d.luam`
cannot also carry the assignment, so the only remaining move is to write a
declaration file describing a global the same project defines — the `config.lua`
mechanism pointed at the project's own source.

Three occurrences in the ported resource: `network`, `Global.Panel` and
`Global.Interaction`, all initialised `nil` and assigned inside a handler.

## Options Considered

| Option | Spelling | Cost | Decision |
|---|---|---|---|
| Widen a global initialised `nil` to `any` | none | Low | Reject — silently drops checking on exactly the globals a resource cares about |
| Infer the union of every assignment in the project | none | High | Reject — order dependent, and a diagnostic would name a file the author is not editing |
| Allow an annotation on a global assignment | explicit | Medium | Accept |
| Allow `declare` in ordinary source | explicit | Medium | Reject — `declare` means "described elsewhere", and this global is defined here |

The accepted row keeps the rule the language already has for a local: the
annotation is the contract and the initialiser is checked against it.

## Scope

- **In:** A type annotation on a global assignment statement at the top level of a
  file, its uniqueness across the project, and the checking of every later
  assignment and read against it.
- **Out:** An annotation on a nested assignment or on a field path, which stays a
  plain assignment. Any inference change for an unannotated global, which keeps
  behaving as it does today. Any change to the emitted Lua: the annotation is
  erased.

## Steps

- [ ] Parse `name: Type = expression` as a top-level global declaration, reusing
      the local-declaration annotation production, and reject the form anywhere
      but the top level with a diagnostic that names the restriction.
- [ ] Check the initialiser against the annotation, so `network: Network = nil`
      reports and `network?: Network = nil` is accepted — the optional marker is
      how the author says the global starts empty.
- [ ] Publish the annotated global to the project surface with its type and its
      environment, the way a `declare` global already travels, so another file
      reads the declared type rather than `any`.
- [ ] Report a second annotation for the same global name in the project as a
      duplicate, and check an assignment in another file against the annotation.
- [ ] Record what happens when a `.d.luam` and an annotated assignment describe
      the same global: the declaration wins, matching the rule already documented
      for `declare`, and the assignment is checked against it.
- [ ] Narrow an annotated global the way a local narrows, so
      `if network then network:init() end` works.

## Acceptance Criteria

- [ ] The reproduction compiles when written `network?: Network = nil`, and
      `network:init()` inside a nil guard resolves.
- [ ] `network: Network = nil` reports `check-type-mismatch`.
- [ ] The annotation inside a function body reports, naming the top-level rule.
- [ ] Another file reads the global with its annotated type, and using a `server`
      global in a `client` file reports the environment diagnostic.
- [ ] An unannotated global behaves exactly as it does today, proven by an
      existing test.
- [ ] The emitted Lua is the assignment without the annotation.
