# 07.01 - Add incremental compilation and cache

> File: `.claude/plans/07.01-incremental-cache.md`

## Objective

Cache ASTs and type results per file, track the dependency graph, and rebuild
only changed files and their dependents.

## Scope

- **In:** Per-file AST/type cache, dependency graph, invalidation on change,
  emit-only-changed-files.
- **Out:** Full-project parallel builds.

## Steps

- [x] Introduce a build graph keyed by file.
- [x] Cache parse and type results per file version.
- [x] Invalidate dependents when an upstream file changes.
- [x] Emit only files whose generated Lua changed.

## Acceptance Criteria

- [x] Editing one file rebuilds only affected outputs.
- [x] Cache invalidates correctly on dependency changes.
- [x] Build time scales with the changed set, not the whole project.
