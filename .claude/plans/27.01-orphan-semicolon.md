# 27.01 - Repair the orphan semicolon left by an erased declaration

## Objective

Stop emitting a bare `;` when a declaration that has no runtime form is written with a trailing semicolon, because Lua 5.1 has no empty statement and the generated file fails to load.

## Context

`sourceEdits` blanks an erasure span by replacing every non-newline character with nothing. The span covers the declaration but not the semicolon the author wrote after it, so `interface I { name: string };` emits a lone `;`. Reproduced with an interface at the start of a file, an interface in the middle of a file, and a `type` alias. No diagnostic reports it.

Lua 5.1 defines a chunk as a sequence of statements each followed by an optional semicolon. A semicolon with no preceding statement is a syntax error. Lua 5.2 introduced the empty statement; MTA runs 5.1.

## Scope

- **In:** Absorbing a trailing semicolon into the erasure span, for every declaration kind that erases to nothing, in development and release builds alike.
- **Out:** Any change to how erased declarations are rendered. That is 29.3.

## Steps

### T-01 - Establish the failing case

**Agent:** architecture-engineer

- [x] Add fixtures for an erased declaration with a trailing semicolon at the start of a file, in the middle of a file, and as the only statement.
- [x] Cover interface, type alias, declare, and event declarations.
- [x] Confirm each currently emits a bare semicolon.

### T-02 - Absorb the semicolon into the erasure

**Agent:** architecture-engineer

- [x] Extend the erasure span produced by the parser, or the replacement built in `sourceEdits`, to include a semicolon that directly follows the declaration.
- [x] Preserve the line count: the absorbed semicolon becomes blank, it never disappears.
- [x] Note for 29.3: once the span includes the semicolon, a development build preserves that token inside the comment, while a release build keeps it blanked.
- [x] Leave intervening whitespace and comments untouched.

### T-03 - Confirm the canonical path agrees

**Agent:** architecture-engineer

- [x] Verify the non-source-preserving emitter never produces the same orphan.
- [x] Add a guard test asserting that no generated line consists only of a semicolon.

## Acceptance Criteria

- [x] No erased declaration produces a bare semicolon in any build mode.
- [x] Line counts are unchanged by the repair.
- [x] Existing emitter snapshots change only where an orphan semicolon was present.
- [x] `pnpm typecheck` and `pnpm test` pass.
