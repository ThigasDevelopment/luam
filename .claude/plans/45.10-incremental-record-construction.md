# 45.10 - Build a record over several statements

> File: `.claude/plans/45.10-incremental-record-construction.md`

## Objective

Let a value reach its declared shape across more than one statement, which is how
a Lua table whose fields depend on its own earlier fields is built, and let a key
be added to an inferred literal.

## Reproduction

Two halves of one problem. A declared target rejects a partial literal:

```luam
class ClientBaseAPI {
    ui: ClientUI

    constructor = function ()
        self.ui = { screen = { guiGetScreenSize() } }
        # check-type-mismatch: Keys "scale", "fonts" are missing from "ClientUI".

        self.ui.scale = math.max(0.70, self.ui.screen[2] / 1080)
        self.ui.fonts = loadFonts(self.ui.scale)
    end
}
```

The two missing keys are computed **from** the first one, so no single literal can
carry them. An inferred literal rejects a new key:

```luam
local data = { owner = owner, plate = plate }
data.cacheTime = getRealTime().timestamp
# check-unknown-record-key: "cacheTime" is not a key of "{ owner: string, plate: string }".
```

Five occurrences of the first shape in the ported resource — `ClientUI`,
`CoreModules`, `CoreRepositories`, `CoreServices`, `InteractionPrice` — and one of
the second.

## Options Considered

| Option | Catches a genuinely missing key | Cost | Decision |
|---|---|---|---|
| Accept any partial literal for a record target | No | Low | Reject |
| Definite assignment over the enclosing block: a partial literal is accepted when every missing key is assigned before the value escapes | Yes | Medium | Accept |
| An explicit partial spelling the author opts into | Yes | Medium | Reject — it taxes the common case and adds surface |
| Nothing; the author annotates every field optional | No — it makes every read optional | Low | Reject |

For the second half, an inferred literal that a later statement extends is not a
closed record. Widening it to include the assigned key is the smaller change and
keeps the closed behaviour for a literal nobody extends.

## Scope

- **In:** A partial table literal assigned to a record, interface or class-typed
  target, completed by later assignments in the same block; and a key added to an
  unannotated literal local or field.
- **Out:** Completion across a function boundary, across a loop, or through a
  closure — those keep reporting. Any relaxation for a value passed as an argument
  or returned before it is complete. Any change to the emitted Lua.

## Steps

- [x] For the declared target: hold the missing keys as an obligation on the
      access path, discharge each one on assignment, and report at the point the
      value first escapes — a read of the whole value, an argument, a return, or
      the end of the block — naming only the keys still missing.
- [x] Reuse the invalidation rules ADR-025 already defines for a path, so a write
      to a prefix, a closure or a loop clears the obligation and the diagnostic
      returns.
- [x] Report the residual failure at the escape point, not at the literal, and
      point the message at the literal as the secondary location, so the author
      sees both ends.
- [x] For the inferred literal: when a later statement in the same scope assigns a
      key the literal does not declare, widen the inferred type to include it
      instead of reporting. Keep `check-unknown-record-key` for a **read** of an
      undeclared key and for any annotated record.
- [x] Confirm neither change touches the emitted Lua.

## Acceptance Criteria

- [x] The `ClientBaseAPI` constructor compiles, and `self.ui.fonts` carries its
      declared type after the assignment.
- [x] Removing the `self.ui.fonts` assignment reports the one missing key, at the
      escape point.
- [x] Passing `self.ui` to a function before it is complete reports.
- [x] `local data = { a = 1 } data.b = 2 print(data.b)` compiles; `print(data.c)`
      reports `check-unknown-record-key`.
- [x] A field annotated with a record type still reports an undeclared key on
      assignment.
- [x] The emitter baseline is byte identical.
