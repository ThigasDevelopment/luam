# 05.01 - Scaffold LSP server on compiler APIs

> File: `.claude/plans/05.01-lsp-server.md`

## Objective

Create the `lsp` package that starts a Language Server and shares the
compiler's lexer, parser, checker, and diagnostics.

## Scope

- **In:** LSP connection, document sync, text document store, environment
  detection per file, publish diagnostics.
- **Out:** Completion, hover, definition, references, rename.

## Steps

- [x] Create `packages/lsp` and initialize the LSP server.
- [x] Serve documents with the language id `luam` and the `.luam` extension
      ([ADR-002](../docs/adr/002-luam-source-file-extension.md)).
- [x] Implement text document sync and open/change handling.
- [x] Run the compiler per file and publish diagnostics.
- [x] Detect file environment for later API scoping.

## Acceptance Criteria

- [x] LSP publishes diagnostics for a changed document.
- [x] Diagnostics clear when errors are fixed.
- [x] Environment detection is correct per file path.
