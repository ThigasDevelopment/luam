# 31.01 - Add reference-driven injection and make threads and async native

## Objective

Give the language its own standard libraries: Lua that ships with Luam, typed
for the checker and the editor, and injected by the compiler when the code names
it.

## Delivered

A third injection trigger exists alongside the two that came before.
`automatic` fires on an emitted language feature, `manual` is an opt-in in
`luam.json`, and `reference` fires when a module names one of the globals a
library declares.

A library is a data entry — its Lua file, the globals it declares, and the
helpers it requires — so adding one touches no compiler logic. `threads` stopped
being `manual`, and a resource that names none of the library globals ships
neither file.

## Scope

- **In:** The `reference` trigger, the library data entries, `meta.xml` ordering
  by requirement, and typing `sleep`, `Threads` and `Async` in
  `LUAM_RUNTIME_GLOBALS`.
- **Out:** Checking a method call on a library instance. `obj:method()` on a
  non-element receiver has been unchecked since milestone 2.

## Steps

**Agent:** architecture-engineer

      a global a library declares.
- [x] Express each library as a data entry: Lua file, declared globals, required

### T-02 - Make threads and async native

**Agent:** architecture-engineer

- [x] Move `threads` off `manual`, so `sleep` and `Threads` pull it in.
- [x] Chain requirements: `Async` pulls `async` in, and `async` pulls `threads`.
- [x] Order a library after everything it requires in `meta.xml`.
- [x] Type `sleep`, `Threads` and `Async` in `LUAM_RUNTIME_GLOBALS`.

## Acceptance Criteria

- [x] A third injection trigger exists. `automatic` fires on an emitted language
      feature, `manual` is an opt-in in `luam.json`, and `reference` fires when a
      module names one of the globals a library declares.
- [x] A library is a data entry: its Lua file, the globals it declares, and the
      helpers it requires. Adding one touches no compiler logic.
- [x] `threads` stopped being `manual`. `sleep` and `Threads` pull it in; `Async`
      pulls `async` in, and `async` pulls `threads` with it.
- [x] `meta.xml` orders a library after everything it requires, so `threads.lua`
      is written before `async.lua` even though the paths sort the other way.
- [x] `sleep`, `Threads` and `Async` are typed in `LUAM_RUNTIME_GLOBALS`, so the
      checker resolves their members and the editor completes them with no file
      on disk.
- [x] A module that declares its own `sleep` does not pull the library in.
- [x] A resource that names none of them ships neither file.

## Decided during implementation

- **The trigger reads `references`, not `externalReferences`.** A catalog global
  is not an external reference — it resolves — so the borrowed-globals map never
  sees `Async`. References minus the module's own globals is the honest input.
- **`RuntimeHelper` in the compiler is now `RuntimeHelperName`.** The two unions
  had drifted, and the compiler's copy silently excluded `env`.

## Closed since

- **A method call on a library instance is checked.** `task:getInterval()`
  returned `any`, because `obj:method()` on a non-element receiver had been
  unchecked since milestone 2. Member *access* was typed; the call was not.
  [32.01](32.01-method-call-checking.md) closed it.
