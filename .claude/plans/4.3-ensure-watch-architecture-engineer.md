# 4.3 — Implement ensure watch loop and MTA sync

> File: `.claude/plans/4.3-ensure-watch-architecture-engineer.md`

## Objective

Deliver `ensure --watch`: build, sync the resource into the MTA server folder,
watch source files, and restart the resource on successful builds.

## Scope

- **In:** Initial full build, resource sync, file watching, incremental
  rebuilds, skip sync on error, RCON/transport restart, terminal feedback.
- **Out:** Incremental AST/type caching (later milestone).

## Steps

- [x] Implement full build + sync of the resource into the MTA folder.
- [x] Implement file watching for source changes.
- [x] On change, rebuild; if diagnostics exist, report and skip sync.
- [x] On success, sync changed files and trigger `refresh`/`restart`.
- [x] Add the configured transport (RCON or documented alternative).

## Acceptance Criteria

- [x] `ensure` performs a full build and sync at start.
- [x] Edits rebuild incrementally and sync only on success.
- [x] Restart triggers against a local MTA server (mocked in CI).
