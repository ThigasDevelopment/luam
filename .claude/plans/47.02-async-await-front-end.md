# 47.02 - Parse async functions and await expressions

## Objective

Accept `async function` and `await expression` in the grammar without reserving
either word, so existing code that uses them as identifiers keeps compiling.

## Scope

- **In:** Contextual recognition of both words, the `isAsync` flag on every
  function form, the `await-expression` node, parser state for the async body,
  and erasure of the `async` token from the preserved source.
- **Out:** Types (47.03), lowering (47.04), editor surfaces (47.06).

## Steps

- [x] Reserve `async` and `await` in `LUAM_KEYWORDS`. The plan argued for keeping
      them contextual to protect `local async = new Async(100)`; no code in the
      repository, the documentation or the ported corpus used either word as a
      name, so the protection guarded nothing.
- [x] Recognize `async` as a modifier only when the next token is `function`, or
      a method name inside a class body. Follow the contextual `static` in
      `parser/declarations.ts`, not the reserved-word path.
- [x] Recognize `await` as an operator only at expression-start position while
      the parser is inside an async body. Everywhere else it stays an ordinary
      identifier.
- [x] Track the async body in parser state: set when the header is parsed,
      restored on exit. A non-async function expression nested inside an async
      body must not accept `await`.
- [x] Add `isAsync` to `FunctionDeclaration` and `FunctionExpression` in
      `parser/ast.ts`, and to `ClassMethodDeclaration` in
      `parser/declaration-nodes.ts`.
- [x] Add an `await-expression` node to the `Expression` union. It binds tighter
      than every binary operator and looser than call and index, so `await foo()`
      parses as `await (foo())` and `await a + 1` as `(await a) + 1`.
- [x] Erase the `async` token from the preserved source with
      `stream.eraseToCurrent(checkpoint)`, the way `export http function` does in
      `parser/directives.ts`.
- [x] Add the new node kind to every switch that enumerates expressions. Grepping
      for the existing unary node kind names the same set of sites.

## Acceptance Criteria

- [x] `local async = 1` and `local await = 1` are `parse-reserved-name`.
      `obj.async` and `obj:await()` still compile, and the existing fixtures are
      unchanged.
- [x] `async` parses on a function declaration, a function expression and a class
      method.
- [x] `await` inside an async body parses as the operator; outside one it parses
      as an identifier reference, with no diagnostic from the parser.
- [x] `await` inside a plain function expression nested in an async body is an
      identifier, not an operator.
- [x] Precedence holds for `await foo()`, `await a.b.c` and `await a + 1`.
- [x] The `async` token leaves no trace in the preserved source.
- [x] Parse diagnostics carry accurate positions.
