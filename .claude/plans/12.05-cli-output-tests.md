# 12.05 - Cover CLI output with style, phase, progress, and diagnostic tests

> File: `.claude/plans/12.05-cli-output-tests.md`
> Tests live in each package's `tests/` folder, never beside the source.

## Objective

Prove that the new output is readable on a terminal, plain everywhere else, and
that none of it changed what the build produces.

## Scope

- **In:** Style and capability detection, phase events, the progress renderer,
  diagnostic layout, and the watch separator.
- **Out:** Asserting on exact colours by eye. Tests assert on the presence and
  placement of markers, not on how pretty they are.

## Steps

- [x] Extend the memory logger fixture with a TTY-capable variant, so both
      rendering paths are exercised from the same tests.
- [x] Style tests: colour and emoji appear with a TTY, and disappear under
      `NO_COLOR`, under `--no-color`, and with the stream piped.
- [x] Phase tests: `onProgress` fires once per file with the right index and
      total, and omitting it leaves the result byte identical.
- [x] Renderer tests: a counted phase draws a bar, a single-step phase does not,
      a fast run prints no intermediate frame, and a failed phase stops the
      sequence.
- [x] Piped-output test: the captured transcript contains no escape sequence and
      no carriage return.
- [x] Diagnostic tests: grouping by file, the caret landing on the reported
      column, the cap summarising the remainder, and the location staying
      parseable.
- [x] Report test: the numbers in the report match what the command reported
      before this milestone.
- [x] Watch test: two rebuilds produce two separated, timestamped blocks.
- [x] Regression test: the generated resource — every file and the manifest — is
      unchanged by this milestone.
- [x] Confirm `pnpm typecheck`, `pnpm build`, and `pnpm test` pass.

## Acceptance Criteria

- [x] Both the TTY and the piped path are covered for every message kind.
- [x] No test asserts on a raw escape sequence outside the style tests.
- [x] The build output is proven identical to before the milestone.
- [x] The suite passes with no skipped tests.
