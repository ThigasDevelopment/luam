# 45.11 - Widen the members of an inferred table literal

> File: `.claude/plans/45.11-widen-inferred-literal-members.md`

## Objective

Stop an unannotated table literal from freezing its members at their literal
types, so a table initialised with zeros can be reassigned with computed numbers.

## Reproduction

```luam
local shape = { x = 0, y = 0 }
shape = { x = 1.5, y = 2.5 }
# check-type-mismatch: Assignment expects "{ x: 0, y: 0 }" but received "{ x: 1.5, y: 2.5 }".
```

The declared type of `shape` is a record whose members are the number literals
`0`, and no other value ever satisfies it. The same shape appears in
`camera-api.luam`, where a shaking offset is initialised
`{ x = 0, y = 0, z = 0 }` and then replaced with computed values.

## Root Cause

`widenLiteral` drops a literal to its base for an inferred local, and
`widenInferred` keeps the shape of a non-empty table literal "minus the flag".
The flag is dropped and the **member** types are not run through `widenLiteral`,
so the record keeps `0` where it should carry `number`. The documented intent —
"`widenInferred` is what an unannotated local and an inferred return use" — is not
what the record arm does.

A string member has the same problem and is worse, because it also picks a member
of a discriminated union: `local state = { kind = 'open' }` cannot later be set to
`{ kind = 'closed' }`.

## Scope

- **In:** Member widening inside `widenInferred` for an unannotated local, an
  unannotated field and an inferred return.
- **Out:** `expectAssignable`, which deliberately does not widen the source, and
  must keep not widening so a literal can still pick a member of a discriminated
  union at an annotated target. Nested literals beyond one level are in scope only
  if the same helper already recurses.

## Steps

- [x] Run each member of a non-empty inferred literal through `widenLiteral`, so
      `{ x = 0 }` infers `{ x: number }` and `{ kind = 'open' }` infers
      `{ kind: string }`.
- [x] Recurse into a nested literal member so `{ position = { x = 0 } }` widens all
      the way down, and pin the depth with a test.
- [x] Leave the annotated path alone: `local state: { kind: 'open' | 'closed' } =
      { kind = 'open' }` must still check, and a discriminated-union argument must
      still select its member from a literal.
- [x] Confirm an array literal already widens its elements, and add the test if it
      does not.
- [x] Confirm no emitter change: inference does not reach the output.

## Acceptance Criteria

- [x] The reproduction compiles.
- [x] `local state = { kind = 'open' } state = { kind = 'closed' }` compiles.
- [x] `local s: { kind: 'open' } = { kind = 'open' }` still checks, and
      `{ kind = 'closed' }` against it still reports.
- [x] Passing `{ kind = 'open' }` to a parameter typed as a discriminated union
      still selects the right member.
- [x] The emitter baseline is byte identical.
