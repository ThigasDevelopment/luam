# 21.4 — Verify CLI compatibility and Lua minification

> File: `.claude/plans/21.4-cli-minifier-tests-test-engineer.md`

## Objective

Prove that the rebuilt CLI retains its public behavior and that production
minification preserves valid Lua 5.1 semantics.

## Scope

- **In:** Unit, integration, and executable smoke tests for command parsing,
  command execution, one-line production output, and failure safety.
- **Out:** Coverage quotas, tests tied to Commander internals, or a live MTA
  server requirement in the standard test suite.

## Steps

- [x] Convert existing parser and dispatcher tests into command-contract tests
      that assert behavior, output stream, and exit code.
- [x] Add one test matrix per command covering valid flags, rejected flags,
      missing values, help, version, and non-interactive operation.
- [x] Add minifier unit fixtures for every lexical boundary that requires a
      separator and for each Lua string/comment form.
- [x] Add resource integration fixtures for tree and bundle layouts, all three
      environments, helpers, `config.lua`, assets, and `loadOrder`.
- [x] Validate generated scripts with a Lua 5.1 interpreter or parser pinned for
      test use; do not substitute a Lua dialect with incompatible syntax.
- [x] Assert semantic execution for representative MTA-safe Lua fixtures where
      an interpreter is available.
- [x] Assert no write or prune occurs when compilation or minification fails.
- [x] Add CLI executable smoke tests to CI for global and command-specific help
      plus a production build.

## Acceptance Criteria

- [x] All existing valid CLI invocations retain their exit code and material
      output after migration.
- [x] Invalid syntax and command-option combinations return `2` without invoking
      command side effects.
- [x] Production fixture scripts are one line, parse as Lua 5.1, and preserve
      expected output.
- [x] Tree and bundle production outputs preserve manifest order and helpers.
- [x] `ensure` and `dev` regression fixtures stay readable and source-mappable.
- [x] `pnpm typecheck`, `pnpm test`, CLI bundle, and executable smoke tests pass.
