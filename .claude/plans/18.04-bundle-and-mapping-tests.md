# 18.04 - Cover both output layouts and position resolution with tests

> File: `.claude/plans/18.04-bundle-and-mapping-tests.md`

## Objective

Lock the two output layouts, the semantics the bundle has to preserve, and the
resolution of a generated position back to Luam source.

## Scope

- **In:** Compiler tests for bundle assembly and the line map, CLI regression
  tests for both layouts and for `luam trace`, snapshots for the bundled
  `meta.xml` and the map file, and executable checks of the preserved Lua
  semantics.
- **Out:** Benchmarks, and any test that requires a running MTA server.

## Behavior Contract

The suite fails if a bundle changes the semantics a separate chunk gives today,
if either layout drifts from its snapshot, or if a position resolves to a line
other than the authored one.

## Steps

- [ ] Add a fixture project with modules in all three environments, a helper
      chain, `config.lua`, `.env`, assets, and a `loadOrder` entry.
- [ ] Snapshot the bundled `meta.xml`, the three bundles, and the map file for
      that fixture, and snapshot the tree layout for the same fixture.
- [ ] Assert bundle membership and ordering: helpers before modules, helper
      order by `helperDepth`, module order matching `sourceEntries` and
      `loadOrder`, and `config.lua` and `.env` outside every bundle.
- [x] Assert an environment with no contribution produces no bundle and no
      `<script>` entry.
- [ ] Assert the bundle paths: the three bundles are the only entries under
      `src/`, `config.lua` and `.env` are at the resource root, assets keep their
      authored paths, and none of this moves when `sourceDirs` is renamed.
- [ ] Execute the generated bundles under a Lua 5.1 interpreter where available,
      and otherwise assert structurally: a file-level `local` is not visible
      across modules, a module with 200 file-level locals loads, and
      `error(message, 2)` reports the same position in both layouts.
- [x] Assert `project-bundle-toplevel-return` and
      `project-bundle-output-collision` fail the build and write nothing.
- [x] Assert idempotence and layout switching: a second build writes nothing, and
      switching layouts in a populated target leaves no stale file.
- [ ] Assert `ensure` and `dev` output is unchanged against the pre-existing
      snapshots.
- [ ] Cover the line map: identity for a flat module, the `control-flow` offset,
      class methods and generated accessors with their symbols, and equality
      between a cached and an uncached module.
- [ ] Cover `luam trace`: a bundle position, a tree position, a pasted MTA log
      line, several positions on standard input, an uncovered position, and an
      unknown map version.
- [ ] Cover `luam dev` formatting for a resolved and an unresolved record.

## Acceptance Criteria

- [x] `pnpm typecheck` and `pnpm test` pass, with the new suites included.
- [ ] Snapshots exist for the bundled `meta.xml`, each bundle, the map file, and
      the tree layout of the same fixture.
- [ ] Every semantic listed in ADR-010 as preserved has a test that fails if it
      is broken.
- [x] Every diagnostic introduced in 20.1 and 20.3 is asserted by code and by
      message.
- [x] Position resolution is asserted end to end, from a generated line to the
      authored line and symbol, in both layouts.
