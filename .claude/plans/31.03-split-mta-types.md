# 31.03 - Split mta-types into handwritten and generated

## Objective

Separate what a maintainer writes from what the generator produces, so 105 flat
files become a reviewable package with an obvious boundary.

## Delivered

`packages/mta-types/src` holds 11 handwritten modules and one `generated/`
directory. Generated modules live in `generated/api`, `generated/oop`, and two
data files, and the generator both writes those paths and prunes stale files
from them.

No import path outside the package changed: the public surface is still the root
modules, and `@mta-types/catalog` resolves as before.

## Scope

- **In:** The `src` layout, the generator's output paths and pruning, and the
  alias-only import convention inside the package.
- **Out:** The catalog content itself, and any change to the public import
  surface.

## Steps
