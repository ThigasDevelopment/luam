# 13.01 - Move runtime helpers out of `src` into `lib/<environment>`

> File: `.claude/plans/13.01-helper-library-directory.md`
> This runs first. A helper that stays inside `src/` would be matched by the
> source wildcard 13.2 introduces as well as by its own explicit entry, and
> loading `class.lua` twice resets the class registry.

## Objective

Relocate every runtime helper from `src/<environment>/lib/` to
`lib/<environment>/`, so the source tree the wildcards cover contains only
author-written modules.

## Scope

- **In:** `libraryPath`, the manifest entries for helpers, the CLI writer and
  pruner, the scaffolded project, and every fixture and snapshot that names a
  helper path.
- **Out:** Wildcards and load order (13.2), manifest formatting (13.3).

## Steps

- [ ] Change `libraryPath` in `packages/compiler/src/project/resource-layout.ts`
      to `lib/<environment>/<file>`. The environment split established by
      [ADR-003](../docs/adr/003-mirror-source-tree-in-generated-resource.md)
      is preserved; only the directory changes.
- [ ] Keep helpers ahead of every other script in `manifestScripts`, and keep
      them explicit entries — they are never covered by a wildcard.
- [ ] Update the CLI pruner so `lib/` is part of the removable set. It is
      generated output, not a source directory, and a helper that stops being
      required must disappear from the resource.
- [ ] Confirm nothing reads a helper through `src/`: the template framework, the
      `luam init` scaffold, `examples/resource`, and the LSP.
- [ ] Rewrite the affected fixtures and snapshots in one pass, so 13.2 and 13.3
      do not rewrite them a second time.

## Acceptance Criteria

- [ ] `class.lua` required by a shared module lands at `lib/shared/class.lua`
      and is declared once in the manifest.
- [ ] The `env` helper, which pins its own environment, still lands on the
      server side — at `lib/server/env.lua`.
- [ ] No generated file lives under `src/<environment>/lib` after a build, and a
      rebuild of a project that previously produced one removes it.
- [ ] `pnpm typecheck`, `pnpm build`, and `pnpm test` pass.
