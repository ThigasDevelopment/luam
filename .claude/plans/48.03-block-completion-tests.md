# 48.03 - Cover block completion in the editor tests

## Objective

Pin down what the block items insert and, more importantly, where they refuse to
appear, so a later change to the completion pipeline cannot start writing `end`
into strings or into blocks that already have one.

## Scope

- **In:** `packages/lsp/tests/block-completion.test.ts` and a unit suite for the
  block scanner.
- **Out:** VS Code integration tests. The extension forwards the item unchanged;
  there is nothing there to assert that the LSP suite does not already cover.

## Steps

- [x] Follow the shape of
      [completion.test.ts](../../packages/lsp/tests/completion.test.ts): drive
      `LanguageService`, place the cursor with `markerAt`, and read the items
      back from `service.completion`.
- [x] Assert the insertion, not just the label: `insertText`, `filterText`,
      `insertTextFormat` and `insertTextMode` for `then .. end`, `do .. end` and
      `until condition`.
- [x] Assert the refusals, one test each: inside a string, inside a line comment,
      inside a block comment, in a type annotation, after `.` and after `:`, and
      inside a call's arguments.
- [x] Assert the balance rule: on a closed `if ready then return end` re-typing
      `then` offers the item without preselect; on an unclosed `if` it is
      preselected and first in the list.
- [x] Assert the plain-text path by calling `completionAt` directly with
      `snippets` false, the way
      [event-handler-snippet.test.ts](../../packages/lsp/tests/event-handler-snippet.test.ts)
      covers its own fallback: no tab stops, the same three lines.
- [x] Unit-test `blockContext` on its own: nested blocks, a `do` closing a `for`
      header versus a bare `do` block, `elseif` reopening a header, `repeat`
      closed by `until`, an `end` written inside a string, and an unterminated
      block at end of file.
- [x] Add one regression test that the plain `then`, `do` and `until` keywords
      are still in the list beside the new rows.

## Acceptance Criteria

- [x] Every insertion field of every block item is asserted, not inferred.
- [x] Each refusal context has its own named test.
- [x] The scanner suite covers nesting, `elseif`, strings and an unclosed block.
- [x] `pnpm -r test` passes and the LSP suite gains no snapshot churn.
