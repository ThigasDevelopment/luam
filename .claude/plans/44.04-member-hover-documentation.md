# 44.04 - Record what a property hover answers

> File: `.claude/plans/44.04-member-hover-documentation.md`

## Objective

State what the editor answers for a property, including a narrowed one, and note
that the fix reaches an editor only through a new extension build.

## Scope

- **In:** The editor section of both locales, and the changelog.
- **Out:** New language documentation; nothing about the language changed.

## Steps

- [ ] Document that a property hover reports the type the checker gave the access,
      narrowed where a guard narrowed it, and that a same-named declaration
      elsewhere in the file never answers for it.
- [ ] Add the changelog entry and name the extension version that carries it.
- [ ] Record that an editor still running an older build keeps the old answers
      until the extension is reinstalled and the extension host restarted.

## Acceptance Criteria

- [ ] Both locales carry the same wording and stay in parity.
- [ ] The changelog names both defects by what the user saw.
