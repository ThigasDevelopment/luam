# 1.4 — Implement type checker and diagnostics

> File: `.claude/plans/1.4-type-checker-architecture-engineer.md`

## Objective

Deliver a binder and type checker that validates Luau-style annotations
(`local x: number`, function parameter and return types) on typed Lua source,
including calls, returns, optionals, and unions, and produces typed
diagnostics.

## Scope

- **In:** Symbol binding, primitive types, `?`, `|`, aliases, function
  signatures, strictness modes, diagnostic model.
- **Out:** Class and interface contracts (later milestone).

## Steps

- [x] Define the type model: primitives, optional, union, function, table, unknown.
- [x] Implement a binder that registers locals, functions, and aliases.
- [x] Implement expression checking with inference for unannotated values.
- [x] Validate annotations on `local` declarations and function signatures.
- [x] Validate assignments, call arguments, and return statements.
- [x] Implement `#!nocheck`, `#!nonstrict`, and `#!strict` modes.

## Acceptance Criteria

- [x] Fixtures with type errors produce diagnostics and no output.
- [x] Valid typed fixtures pass cleanly.
- [x] Strictness modes behave as documented.
