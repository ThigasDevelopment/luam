# 51.10 - Cover the reformulated manifest in the tests

## Objective

Lock the reformulation to two authored `meta.xml` files, so the emitter is
verified against what a resource author actually writes rather than against its
own previous output.

## The two fixtures

- **`heaven-roleplay`** — eight ordered blocks interleaving server and client,
  two scripts at the resource root, helpers under `src/utils/lib/`, non-recursive
  `*` and recursive `**` in one file, one wildcard for a directory of images, and
  three section comments over seven visual blocks. This is the file the milestone
  exists for.
- **`bcg`** — the table-form sketch: a nested `info.author` with an extra
  attribute, two `dependencies`, two libraries of which one is client-only,
  `oop = false`, a pinned version on both sides, and four `files` entries in three
  blocks.

Both are committed as an authored `meta.xml` next to the manifest, and the test
asserts the generated file equals the authored one byte for byte. A snapshot the
generator wrote cannot catch the generator being wrong about the standard.

## Scope

- **In:** The two fixtures, the diagnostic matrix, the round-trip properties, and
  the migration corpus.
- **Out:** Library distribution, which keeps its current behaviour in this
  milestone and is covered by the tests it already has.

## Steps

- [ ] Add both fixtures with their authored `meta.xml`, and a test that builds
      each and compares bytes.
- [ ] Add a diagnostic test per code this milestone introduces:
      `config-missing-return`, `config-return-not-a-table`,
      `config-unknown-field`, `config-duplicate-field`,
      `config-script-side-conflict`, `config-missing-script`,
      `config-empty-script-entry`, `config-no-scripts`,
      `config-empty-file-entry`, `config-output-collision`,
      `config-manifest-form`. Each asserts the message, not only the code.
- [ ] Add the ordering properties: moving an entry moves exactly one element;
      deleting a blank line merges exactly two blocks; adding an image to a
      matched directory changes no line of the generated file.
- [ ] Add the round trip: every fixture manifest through `luam format` produces a
      byte-identical `meta.xml`.
- [ ] Add the migration corpus: every manifest in the repository as it stood
      before this milestone, each asserted to migrate to a file whose build
      matches the pre-migration build.
- [ ] Regenerate every affected snapshot and review each diff. A snapshot updated
      without being read is a test that has stopped testing.
- [ ] Add an LSP test for completion in each section and for the caret position of
      a misspelled key.

## Acceptance Criteria

- [ ] Both fixtures build to their authored `meta.xml` byte for byte.
- [ ] Every diagnostic code above has a test that asserts its message.
- [ ] The three ordering properties hold.
- [ ] The format round trip holds for every fixture.
- [ ] Every pre-milestone manifest migrates to an equivalent build.
- [ ] `pnpm -r test`, `pnpm typecheck` and `pnpm conventions` pass.
