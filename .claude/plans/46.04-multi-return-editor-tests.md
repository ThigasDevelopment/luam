# 46.04 - Cover a multi-return local across the editor surfaces

> File: `.claude/plans/46.04-multi-return-editor-tests.md`

## Objective

Lock the reported case and the adjust rules behind it, in the compiler and in
every editor surface that reads a value list, so the two cannot drift apart
again.

## Scope

- **In:** Unit coverage for the extracted distribution, LSP fixtures for hints,
  hover and completion, and a fixture built on the catalog signature that was
  reported.
- **Out:** Benchmarks — the change adds no traversal — and VS Code end-to-end
  automation.

## Steps

- [x] Add compiler unit tests for `distributeValueTypes`: the empty list, a
      non-tuple, a tuple in final position, a tuple in non-final position, a tuple
      followed by a second value, and a value list longer than the tuple.
- [x] Add inlay-hint fixtures for `local a, b, c = triple()`, `local only = f()`,
      `local x, y = 1, triple()`, `local a, b, c = 1`, `local a, b = ...` and a
      declarator annotated in the middle of the list.
- [x] Add a fixture using `getVehicleComponentPosition` so the reported code is a
      test rather than a screenshot, asserting three `: number` hints at three
      offsets on one line.
- [x] Add hover fixtures for the second and third names of a destructured local,
      and one asserting the value text appears on the first name only.
- [x] Add a completion fixture asserting the detail of a name declared by the
      second element of a tuple.
- [x] Assert a hint whose name sits outside the requested range is not emitted
      because a sibling on the same line is inside it.
- [x] Confirm the CLI and the LSP agree: the same source that hints `: string`
      type-checks with `b` as `string`.

## Acceptance Criteria

- [x] Every assertion above has a test, and the ones covering the defect fail
      against the tree as it stands before 46.02 and 46.03.
- [x] `pnpm test` passes across the workspace with no existing fixture rewritten
      to accommodate the change.
- [x] The suites for hover, completion, document symbols, workspace symbols and
      semantic tokens pass untouched.
