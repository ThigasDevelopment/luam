# 36.02 - Extract reusable workflows and pin every action

## Objective

Remove the duplication between the workflows by extracting the shared work into
`workflow_call` units, and close the supply-chain gap where three of the four
workflows reference actions by floating tag.

## Scope

- **In:** Reusable workflows for the verification units, the callers rewritten
  against them, SHA pinning for every third-party action, and the duplicated
  `paths` filter in `docs.yml`.
- **Out:** Changing what the pipeline verifies. This task moves and pins; it
  neither adds nor removes a check. Gate composition belongs to
  [36.03](36.03-merge-gate-and-signal.md).

## Steps

### T-01 - Extract the reusable units

**Agent:** github-engineer

- [x] Create `workflow_call` workflows for the units the contract named:
      typecheck, test matrix, build and smoke, docs verification.
- [x] Declare `inputs` for what varies today — Node version, package filter —
      instead of copying a job.
- [x] Rewrite `ci.yml`, `docs.yml` and `release.yml` as callers. A caller
      declares triggers, concurrency and permissions, and nothing else.

### T-02 - Pin the supply chain

**Agent:** github-engineer

- [x] Pin every third-party action to a full commit SHA with the version in a
      trailing comment, matching what `catalog-refresh.yml` already does.
- [x] Keep first-party references (`./.github/actions/setup`) by path.
- [x] Confirm Dependabot's `github-actions` ecosystem updates SHA pins, and
      adjust `.github/dependabot.yml` if it does not.

### T-03 - Remove the remaining duplication

**Agent:** github-engineer

- [x] Collapse the ten-entry `paths` list `docs.yml` repeats verbatim between
      `push` and `pull_request` into one definition.
- [x] Give every job an explicit `permissions` block per the contract.

## Acceptance Criteria

- [x] No verification step is written in more than one workflow file.
- [x] Every third-party action is pinned to a commit SHA; a floating tag fails
      review.
- [x] Every job declares `permissions`, defaulting to `contents: read`.
- [x] `docs.yml` states its path filter once.
- [x] The checks that run on a `develop` push are identical before and after,
      compared by job name and outcome on one commit.
- [x] Total CI wall-clock does not regress.
