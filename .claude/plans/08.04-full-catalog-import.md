# 08.04 - Import the full MTA catalog

> File: `.claude/plans/08.04-full-catalog-import.md`

## Objective

Replace the 236 hand written MTA declarations with the complete catalog and keep
the compiler fast while doing it.

## Scope

- **In:** Running the generator, reviewing the diff, caching the per-environment
  global scope, element hierarchy and event refresh, documentation updates.
- **Out:** LSP autocomplete features that consume the catalog.

## Steps

- [x] Run the generator and review the diff against the current catalogs,
      confirming the milestone 3 declarations survive or improve.
- [x] Refresh the element type hierarchy and the event catalogs from the same
      source.
- [x] Cache the global scope per environment in
      `packages/compiler/src/checker/globals.ts`. Building a map of every
      declaration for every compiled file does not scale to a full catalog.
- [x] Measure compile time on a multi-file fixture before and after the import
      and record the numbers.
- [x] Update `packages/mta-types/README.md` with the real counts, the generated
      status of each file, and the refresh command.
- [x] Update the milestone 3 deferral notes in the roadmap that this import
      closes.

## Acceptance Criteria

- [x] The catalog covers the Wiki server, client, and shared functions, and the
      count is recorded in the README.
- [x] `pnpm typecheck`, `pnpm build`, and `pnpm test` pass with no changes to the
      existing compiler tests.
- [x] Compiling a file does not rebuild the global scope from the full catalog.
- [x] Compile time for the fixture resource does not regress measurably.
