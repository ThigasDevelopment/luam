# 6.2 — Add automatic listener and command loading

> File: `.claude/plans/6.2-auto-loading-architecture-engineer.md`

## Objective

Load listeners and commands automatically by scanning registered classes and
instantiating those extending `Listener` or `Command`.

## Scope

- **In:** Class hierarchy scan, auto-instantiation with the `Core` instance,
  event and command registration, alias handling.
- **Out:** CLI scaffolding command.

## Steps

- [x] Implement class registry scan for `Listener` and `Command` subclasses.
- [x] Instantiate discovered classes with the `Core` instance.
- [x] Verify event and command registration on start.
- [x] Provide an example handler fixture.

## Acceptance Criteria

- [x] A handler in the handlers folder registers its event automatically.
- [x] A command with aliases registers all aliases.
- [x] The pattern matches `mta-project-base` behavior.
