# 02.03 - Emit classes and enums to Lua runtime calls

> File: `.claude/plans/02.03-class-emitter.md`

## Objective

Lower `class`, `extends`, `new`, `self:super`, and `enum` declarations into
`class 'Name' { ... }` runtime calls and mark runtime helpers as required.

## Scope

- **In:** Class emission, inheritance modifiers, `new` calls, `self:super`,
  enum emission, runtime helper requirement tracking.
- **Out:** Runtime helper injection into resources.

## Steps

- [x] Emit `class 'Name' :extends 'Parent' { ... }` from class AST.
- [x] Emit method entries as `name = function(self, ...) ... end`.
- [x] Emit `new 'Name' (...)`, `self:super(...)`, and `enum { ... }`.
- [x] Mark `class.lua` required when any OOP or enum feature is emitted.

## Acceptance Criteria

- [x] Fixture snapshots match expected `class`/`new`/`enum` Lua output.
- [x] `self:super(...)` emits against the parent method.
- [x] `class.lua` is required only when used.
