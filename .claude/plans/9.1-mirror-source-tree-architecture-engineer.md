# 9.1 — Mirror the source tree in the generated resource

> File: `.claude/plans/9.1-mirror-source-tree-architecture-engineer.md`
> Overlaps 7.1. Both tasks change output paths and the emitted file set. Land
> this one first or 7.1 caches keys that are about to change.

## Objective

Make the generated resource repeat the authored tree exactly, changing only the
extension, so a path in a runtime error maps to a source file without a mental
transformation.

## Scope

- **In:** `outputPath` rewrite, helper relocation to `src/<environment>/lib`,
  explicit script ordering in the manifest.
- **Out:** Copying assets and non-source files (9.2), configuration and
  environment files (9.3).

## Steps

- [x] Rewrite `outputPath` to mirror the path relative to the project root,
      dropping the `lastIndexOf('src')` search.
- [x] Write each helper to `src/<environment>/lib/<file>.lua`, using the
      environment `collectHelpers` already merges from usage.
- [x] Retire the `helperDir` config field and its `runtime` default, or reduce
      it to the `lib` segment name.
- [x] Order `manifestScripts` explicitly: libraries, then configuration, then
      the developer's scripts, instead of relying on alphabetical sorting.
- [x] Keep `findDuplicateOutputs` in the pipeline — two `sourceDirs` entries can
      still produce the same relative path.
- [x] Update fixtures and manifest snapshots for the new paths.

## Acceptance Criteria

- [x] `src/server/modules/example.luam` emits `src/server/modules/example.lua`.
- [x] A source path containing a nested `src` segment emits a mirrored path
      rather than resolving against the last occurrence.
- [x] A helper used only by server files is written under `src/server/lib` and
      typed `server` in the manifest, so no client downloads it.
- [x] A helper used on both sides is written under `src/shared/lib`.
- [x] Manifest order is libraries, configuration, developer scripts, and does
      not change when a source file is renamed.
- [x] Two sources mirroring to the same path still report
      `project-duplicate-output`.
