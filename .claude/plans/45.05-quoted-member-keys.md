# 45.05 - Declare a member whose key is not an identifier

> File: `.claude/plans/45.05-quoted-member-keys.md`

## Objective

Let an interface, an object type and a class declare a key that Lua allows but an
identifier does not spell, so a table keyed `'medium:20'` or `'garage_type'` can
be typed instead of degraded to `table<string, T>`.

## Reproduction

```luam
interface ClientFonts {
    ['medium:20']: DxFont
}
# parse-unexpected-token: Expected a name but found "[".

type Fonts = {
    ['bold:15']: DxFont
}
# parse-unexpected-token: Expected a name but found "["
# parse-unexpected-token: Unexpected "}" in expression.
```

The ported resource declares thirteen font keys of this shape. Every one had to
become `table<string, DxFont>`, which loses the key set, the completion list and
the misspelling check that motivated declaring the interface at all.

The same shape appears in data read from SQL — `data['garage_type']` — and in
every table keyed by an MTA event name or a resource name.

## Scope

- **In:** A quoted string key in an `interface` body, an object type body and a
  class body, with the optional marker, a default where the container allows one,
  and the same key in the member-access, completion and hover paths.
- **Out:** A computed key, a numeric key and a key whose value is not a string
  literal — those are what `table<K, V>` is for. Any change to the emitted Lua.

## Steps

- [ ] Accept `['literal']` wherever the parser accepts a member name today, in
      `parser-declarations` and in the object-type arm of
      `parser-type-annotation`, producing the same member node with the literal
      text as its name.
- [ ] Keep the reserved-word rule intact: a bare `class` or `type` is still a name
      after `.` and `:`, and a quoted key is a second spelling, not a replacement.
- [ ] Report a duplicate key when the quoted form and the bare form name the same
      key, so `name` and `['name']` in one body is one diagnostic and not two
      members.
- [ ] Resolve `value['medium:20']` and `value.name` against the same member table,
      so a quoted key is readable only through the index form and a bare key stays
      readable through both.
- [ ] Emit the key in a class body as the quoted form the runtime needs, and
      assert the generated Lua for a class with such a field.
- [ ] Surface the key in completion and hover with its quotes, so the editor shows
      what the author has to type.

## Acceptance Criteria

- [ ] The thirteen-key `ClientFonts` interface from the ported resource compiles
      and types `self.ui.fonts['medium:20']` as `DxFont`.
- [ ] `self.ui.fonts['medium:21']` is `check-unknown-member` and the message lists
      the declared keys.
- [ ] The same key declared in an object type alias and in a class behaves
      identically.
- [ ] A class with a quoted field emits the quoted key, proven by an emitter
      baseline.
- [ ] Completion after `fonts[` offers the declared keys.
