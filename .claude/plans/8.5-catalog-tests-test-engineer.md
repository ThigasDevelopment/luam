# 8.5 — Cover the full catalog with tests

> File: `.claude/plans/8.5-catalog-tests-test-engineer.md`

## Objective

Lock the catalog against drift and prove a real resource type checks against the
full declaration set.

## Scope

- **In:** Catalog invariant tests, drift detection, spot checks for well known
  signatures, a compiler fixture exercising many APIs.
- **Out:** LSP and CLI tests.

## Steps

- [x] Assert the invariants: every name declared once, every declaration carries
      an environment, and every signature has a valid descriptor.
- [x] Add a drift test that regenerates the catalog and fails when the committed
      files differ from the generator output.
- [x] Spot check signatures that the compiler relies on, including
      `addEventHandler`, `getElementType`, `dxDrawText`, `outputChatBox`, and the
      extension helpers.
- [x] Assert the overrides from 8.3 still win after regeneration.
- [x] Add a fixture resource that calls a broad set of server and client APIs and
      compiles with no diagnostics.
- [x] Add a fixture that misuses an API from the newly imported set and assert
      the environment diagnostic.

## Acceptance Criteria

- [x] The drift test fails when the catalog is edited by hand instead of
      regenerated.
- [x] The broad fixture compiles with no diagnostics.
- [x] Environment diagnostics still fire for newly imported client-only and
      server-only functions.
- [x] `pnpm test` passes across every package.
