# 03.03 - Validate environments for APIs and imports

> File: `.claude/plans/03.03-environment-validation.md`

## Objective

Enforce that a file only uses APIs and imports allowed in its environment.

## Scope

- **In:** API availability check per environment, import direction rules
  (shared imported by server/client; server/client never import each other),
  module environment tagging.
- **Out:** Manifest generation.

## Steps

- [x] Validate every resolved global/API call against the file environment.
- [x] Tag modules with their environment at bind time.
- [x] Validate import directions across environments.
- [x] Report environment violations as diagnostics.

## Acceptance Criteria

- [x] Client-only API in a server file is a diagnostic.
- [x] A server file importing a client-only module is a diagnostic.
- [x] `shared` files cannot import server- or client-only modules.
