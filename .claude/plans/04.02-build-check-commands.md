# 04.02 - Implement build and check commands

> File: `.claude/plans/04.02-build-check-commands.md`

## Objective

Deliver `build` (emit the resource) and `check` (diagnostics only) commands
that use the compiler pipeline and fail on errors.

## Scope

- **In:** Full build orchestration, check mode without emit, exit codes,
  terminal diagnostics and timing output.
- **Out:** Watch mode and incremental caching.

## Steps

- [x] Wire the compiler pipeline into the CLI.
- [x] Discover `**/*.luam` sources and map each one to a `.lua` output
      ([ADR-002](../docs/adr/002-luam-source-file-extension.md)).
- [x] Implement `check` that reports diagnostics and exits non-zero on failure.
- [x] Implement `build` that emits the resource and fails on any diagnostic.
- [x] Add terminal output with file/line diagnostics and build time.

## Acceptance Criteria

- [x] `check` reports diagnostics from fixtures and exits non-zero on failure.
- [x] `build` produces a valid resource or fails without partial output.
- [x] Output is readable in the terminal.
