# 03.01 - Add environment resolution model

> File: `.claude/plans/03.01-environment-model.md`

## Objective

Resolve the environment (`server`, `client`, `shared`) for each source file
from its path or `#!` directive.

## Scope

- **In:** Path-based resolution for `src/server`, `src/client`, `src/shared`,
  directive resolution `#!server`/`#!client`/`#!shared`, conflict errors.
- **Out:** MTA API validation and manifest generation.

## Steps

- [x] Define the `Environment` enum.
- [x] Implement path-based environment resolution over `.luam` files
      ([ADR-002](../docs/adr/002-luam-source-file-extension.md)).
- [x] Implement `#!` directive parsing as an override.
- [x] Report conflicts between path and directive as diagnostics.

## Acceptance Criteria

- [x] Files under the three `src` folders resolve to the right environment.
- [x] Directives override path inference.
- [x] Conflicting directives produce a diagnostic.
