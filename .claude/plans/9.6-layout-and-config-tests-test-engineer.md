# 9.6 — Cover milestone 9 with layout and configuration tests

> File: `.claude/plans/9.6-layout-and-config-tests-test-engineer.md`

## Objective

Lock the mirrored output layout, the ownership rules that keep a rebuild from
destroying hand-edited files, and the boundary that keeps deployment values off
the client.

## Scope

- **In:** Path mirroring, manifest ordering, asset copying and pruning, the
  `.env` write-once rule, `process.env` typing and environment checks,
  declaration files.
- **Out:** Executing generated Lua. No interpreter runs in the test stack, so
  runtime behavior is asserted through emitted output and manifest order.

## Steps

- [x] Snapshot the generated tree for a fixture using all three environments,
      nested module folders, and a nested `src` segment.
- [x] Snapshot `meta.xml` ordering and assert it survives a source rename.
- [x] Assert a server-only helper lands under `src/server/lib` and is typed
      `server`.
- [x] Cover asset copying, binary round-trip, and removal after the source is
      deleted.
- [x] Cover the `.env` lifecycle: first build generates, second build preserves
      an edit, deletion regenerates.
- [x] Assert `.env` never appears as a `<file>` entry.
- [x] Cover the `env` library parser: comments, blank lines, quoted and
      unquoted values, the type coercion rule, a malformed line, a missing file.
- [x] Cover `process.env` typing, unknown-key diagnostics, and rejection from
      client and shared files.
- [x] Assert a `.d.luam` file emits nothing and still resolves in the checker.

## Acceptance Criteria

- [x] `pnpm typecheck` and `pnpm test` pass the full suite.
- [x] Fixture snapshots lock output paths, manifest order, and the generated
      `.env` skeleton.
- [x] A test fails if a rebuild overwrites a hand-edited `build/.env`.
- [x] A test fails if `.env` or a server-only helper becomes client-reachable.
- [x] A test fails if a `.d.luam` file reaches the generated resource.
