# 45.07 - Take type parameters on an interface

> File: `.claude/plans/45.07-generic-interfaces.md`

## Objective

Close the last hole in the generics surface: a `type` alias, a class and a
function may all declare type parameters, and an interface may not.

## Reproduction

```luam
interface Promise<T> {
    state: 'pending' | 'fulfilled' | 'rejected'
    value: T[]
    handlers: fun[]
}
# parse-unexpected-token: Unexpected "interface" in expression.
# parse-invalid-statement: "state" is not a statement.
# parse-unexpected-token: Expected "(" but found "[".
```

The parser does not recognise the `<` after the interface name, abandons the
declaration, and then reads the body as statements — four cascading errors from
one missing production.

The ported resource describes an async library whose contract is
`newPromise<T>` / `await<T>`. Without a generic interface the element type is
lost at the first `await`, and four call sites that should be typed `Vehicle` or
`Vehicle[]` are `any`.

## Context

24.07 delivered erased generic classes and 37.02 delivered generic functions,
both with substitution, inference and constraints already implemented. This task
reuses that machinery for one more declaration form; it is not new type theory.

## Scope

- **In:** Type parameters on an `interface` declaration — with constraints and
  defaults, matching what an alias and a class already accept — substitution when
  the interface is referenced, inference where a generic interface is a parameter
  type, and `implements` against a generic interface.
- **Out:** Variance annotations, which no other declaration form has. Higher
  kinded parameters. Any change to the emitted Lua: an interface is erased.

## Steps

- [x] Parse a type-parameter list after an interface name, sharing the production
      the class declaration already uses, so the constraint and default syntax
      cannot drift between the two.
- [x] Register the parameters in the declaration registry so a member type may
      reference them, including recursively — `next: Promise<T>` inside
      `Promise<T>`.
- [x] Substitute at every reference: an annotation, an alias body, a member type,
      a `declare`, a class `implements` clause and a type argument of another
      generic.
- [x] Check `class C implements Promise<Vehicle>` member by member against the
      substituted contract, and report a mismatch naming the substituted type, not
      the parameter.
- [x] Report a wrong type-argument count as the same diagnostic a generic alias
      reports today, so the three forms speak with one voice.
- [x] Extend hover, completion and the unknown-type check to a generic interface,
      so `Promise` alone names the arity it expects.

## Acceptance Criteria

- [x] The reproduction compiles, and `await(p)` where `p: Promise<Vehicle>` types
      as `Vehicle`.
- [x] A recursive generic interface resolves and does not warn.
- [x] `implements` against a generic interface reports a mismatched member with
      the substituted type in the message.
- [x] A wrong argument count reports the same code a generic alias reports.
- [x] The emitted Lua and the manifest are unchanged.
