# 12.04 - Group diagnostics by file and show the offending source line

> File: `.claude/plans/12.04-diagnostic-layout.md`
> Can run in parallel with 12.2 and 12.3. It depends on the style layer only.

## Objective

Make a failing build readable: diagnostics grouped under the file they belong
to, the offending line shown with a caret under the column, and the machine
readable location kept intact.

## Scope

- **In:** Grouping, the source excerpt, the caret, colour applied through 12.1,
  and a cap on how much is printed.
- **Out:** Code actions, automatic fixes, anything that edits source.

## Steps

- [x] Group diagnostics by file, printing the path once as a header and the
      entries under it in position order.
- [x] Read the offending line from the source the build already has in memory
      and print it beneath the entry, with a caret run under the column.
- [x] Size the caret run from the token when the diagnostic carries one, and
      fall back to a single caret when it does not.
- [x] Keep a plain `path:line:column` string on every entry, so the editor and
      the terminal keep linkifying it.
- [x] Cap the output: print at most a set number of entries per file and a set
      number of files, then summarise the remainder rather than flooding the
      scrollback.
- [x] Keep the diagnostic code visible. It is what the documentation indexes.
- [x] Preserve the existing hints, which milestone 7 added, as a muted line
      beneath the message.
- [x] Fall back to the current one-line-per-diagnostic format when the stream is
      not a TTY, so CI logs and the existing tests are unaffected.

## Acceptance Criteria

- [x] Three errors in one file print one path header and three entries.
- [x] Each entry shows the source line and a caret under the reported column.
- [x] A diagnostic whose position is the start of the file does not crash the
      excerpt reader.
- [x] Piped output matches today's format exactly.
- [x] Beyond the cap, the summary names how many entries were withheld.
- [x] Every diagnostic still carries its code and a parseable location.
