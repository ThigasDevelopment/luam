# 1.6 — Cover milestone 1 with fixtures and snapshot tests

> File: `.claude/plans/1.6-language-tests-test-engineer.md`

## Objective

Deliver fixture-based snapshot coverage for the lexer, parser, type checker,
and Lua 5.1 emitter so milestone 1 behavior is locked and regressions are
caught.

## Scope

- **In:** Fixture files, lexer/parser/AST snapshots, emitter Lua snapshots,
  diagnostics snapshots, and Vitest setup wiring.
- **Out:** Classes, enums, environments, and manifest tests (later milestones).

## Steps

- [x] Create a `fixtures/` tree under `packages/compiler/test/` with small programs covering literals, operators, template strings, functions, control flow, and type annotations.
- [x] Add lexer snapshot tests asserting token streams and positions.
- [x] Add parser snapshot tests asserting AST shape and syntax diagnostics.
- [x] Add type checker tests for valid fixtures and fixtures with type errors.
- [x] Add emitter snapshot tests asserting Lua 5.1 output for statements, compound assignment, template strings, and extension rewrites.
- [x] Wire tests into `pnpm --filter compiler test` and verify they pass.

## Acceptance Criteria

- [x] `pnpm --filter compiler test` passes the full suite.
- [x] Snapshots cover every literal, operator, and statement form in scope.
- [x] Template strings, compound assignment, and native extensions are snapshot-verified.
