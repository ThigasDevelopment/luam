# 3.4 — Generate resource manifest and assembly

> File: `.claude/plans/3.4-manifest-resource-assembly-architecture-engineer.md`

## Objective

Generate `meta.xml` with correct `type` attributes and assemble a resource
with compiled files and required runtime helpers in load order.

## Scope

- **In:** Manifest generation, runtime helper ordering before dependents,
  shared-code dual emission, resource output directory assembly.
- **Out:** CLI commands that drive the build.

## Steps

- [x] Implement manifest generation with `type="server"`, `type="client"`, `type="shared"`.
- [x] Order runtime helper `<script>` entries before dependents.
- [x] Emit shared files with executable code for both environments.
- [x] Copy compiled files and helpers into the resource folder.

## Acceptance Criteria

- [x] A fixture with all three environments produces a valid resource.
- [x] Runtime helpers load before dependent scripts in `meta.xml`.
- [x] Shared executable code appears for both sides.
