# 51.09 - Give the table form its editor surfaces

## Objective

Make the editor as good at the table form as it is at the assignment form:
completion that knows which section the cursor is in, hover that states the
owner, and diagnostics anchored at the key.

## Scope

- **In:** Completion, hover, diagnostics and the grammar for the new shape, plus
  the migration code action from 51.08.
- **Out:** `.luam.server` and `.luam.formatter`, which keep their own field
  tables and are untouched.

## Steps

- [ ] Rework `manifest-scope` to resolve a position to a path inside the manifest
      table rather than to a top-level assignment. The cursor inside
      `environment = { }` resolves to `environment`, and inside a `scripts` entry to
      `scripts[].path` or `scripts[].type`.
- [ ] Offer section keys at the top level of the table form, field keys
      inside a section, and nothing else. A section already written is not offered
      again.
- [ ] Offer `'server'`, `'client'` and `'shared'` as the only values of
      `scripts[].type`, from the catalog rather than from a literal in the
      completion code.
- [ ] Offer the installed package names for `libraries` entries, from the same
      resolution 51.07 uses.
- [ ] Make hover state the field's section, its type, its default and its rule,
      the four the catalog already carries.
- [ ] Answer as much of the compiler-option question in the editor as the editor
      can answer. `noUnusedLocals`, `noImplicitGlobals` and `noUnusedParameters`
      each describe a diagnostic the language server can already compute, show at
      the offending line and fix in place, which is worth more than a manifest
      boolean that turns it into a build failure. Whatever 51.02 decides to keep
      as a field, this task delivers the editor half.
- [ ] Anchor every manifest diagnostic at the key rather than at the statement, so
      the caret lands where the edit goes.
- [ ] Update the TextMate grammar and the semantic token provider for the new
      shape, and update the grammar test that pins them.

## Acceptance Criteria

- [ ] Completion at the top level of the table form offers exactly the
      sections, minus those already written.
- [ ] Completion inside `environment = { }` offers only environment fields.
- [ ] Completion at `type = ` inside a `scripts` entry offers exactly three
      values.
- [ ] Hover on any field states its section and its default.
- [ ] Every compiler option that survives 51.02 has an editor surface that shows
      what it reports, at the line it reports it, without a build.
- [ ] A misspelled key shows the caret on the key.
- [ ] The migration code action appears on an assignment-form manifest and on no
      other file.
- [ ] The grammar test covers a table-form manifest, and the theme sample
      fixture is updated to one.
