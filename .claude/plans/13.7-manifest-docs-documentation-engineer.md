# 13.7 — Document the manifest standard and the directive removal

> File: `.claude/plans/13.7-manifest-docs-documentation-engineer.md`
> A language losing two keywords and a resource changing layout are both
> breaking changes for anyone who already wrote against them.

## Objective

Move [ADR-008](../docs/adr/008-generated-manifest-standard.md) to `Accepted`,
document the manifest standard and `loadOrder`, and record the removals where a
reader would look for them.

## Scope

- **In:** ADR-008, ADR-003 and ADR-007 supersession notes, `language-design.md`,
  `architecture.md`, `project.md`, `CHANGELOG.md`, and the README where it shows
  a resource layout.
- **Out:** New product decisions. This task writes down what 13.1 to 13.5 did.

## Steps

- [ ] Move ADR-008 from `Proposed` to `Accepted` and fold the three resolved
      open questions into its decisions: `loadOrder` in `luam.json`, the removal
      of `setting` and `depends`, and the version lookup with cache and
      fallback.
- [ ] Add a supersession note to
      [ADR-003](../docs/adr/003-mirror-source-tree-in-generated-resource.md) for
      the helper directory and to
      [ADR-007](../docs/adr/007-build-directives.md) for the two removed
      directives and the shared export collapse.
- [ ] Remove `setting` and `depends` from `language-design.md`, leaving `export`
      documented as the only build directive, and say plainly that they were
      removed and why.
- [ ] Document the generated resource layout — `lib/<environment>/`,
      `config.lua`, `src/`, assets — and the manifest standard with a worked
      example, in `architecture.md`.
- [ ] Document `loadOrder` in the `luam.json` reference: what it accepts, that
      order is meaningful for scripts and assets alike, and that an entry
      matching no file fails the build.
- [ ] Write the milestone 13 `CHANGELOG.md` entry with a **Removed** section,
      and state the reproducibility caveat the version lookup introduces.
- [ ] Sweep the docs for any remaining reference to `src/<environment>/lib`, to
      the enumerated script list, or to `isCached`.

## Acceptance Criteria

- [ ] No document describes `setting`, `depends`, `isCached`, or a helper under
      `src/`, verified by a repository-wide search.
- [ ] ADR-008 is `Accepted` and carries no open question.
- [ ] `CHANGELOG.md` has a milestone 13 entry with Added, Changed, and Removed.
- [ ] Every documented example of a manifest matches what the generator now
      produces.
