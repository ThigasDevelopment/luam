# 13.03 - Bring the manifest emitter to the authored standard

> File: `.claude/plans/13.03-manifest-standard-emitter.md`
> Everything here is formatting and attribute policy. The set of entries is
> decided by 13.2; this task decides how they read.

## Objective

Make `generateManifest` produce the file a resource author would have written by
hand — the standard recorded in
[ADR-008](../docs/adr/008-generated-manifest-standard.md).

## Scope

- **In:** `<info>` attributes, omission of default attributes, the `cache` rule,
  the shared export collapse, section comments, and element order.
- **Out:** Which scripts and files exist (13.2), `min_mta_version` (13.5),
  removing directives (13.4).

## Steps

- [ ] Drop `name` from `<info>`. MTA takes the resource name from the containing
      folder; `name` in `luam.json` keeps naming the output directory and the
      resource `ensure` restarts. Attribute order becomes `author`, `type`,
      `version`, `description`.
- [ ] Omit any attribute equal to the MTA default. `type="server"` is the
      default for `<script>` and `<export>`, so a server entry carries neither.
- [ ] Make `cache="false"` unconditional on every `client` and `shared` script,
      in development and production alike. Remove `isCached` from
      `ManifestScript` and from every construction site.
- [ ] Collapse a shared export into one `<export type="shared" />` entry,
      replacing the server/client pair milestone 10 emits. This reverses that
      part of [ADR-007](../docs/adr/007-build-directives.md); the duplicate
      export check keeps its current shape, it just compares one entry per name
      per side rather than the expanded pair.
- [ ] Add a section comment above each group, emitted only when the group has at
      least one entry, so an empty group leaves no orphan comment. No blank
      lines between groups.
- [ ] Fix element order: `<oop>`, info, scripts, exports, files,
      `min_mta_version` (13.5 fills it in). Keep four spaces, double quotes,
      `attr="value"`, and the self-closing form with a leading space.

## Acceptance Criteria

- [ ] A server script is `<script src="src/server/**/*.lua" />` with no `type`
      and no `cache`; a shared one carries `type="shared" cache="false"`.
- [ ] `<info>` has no `name` attribute, and renaming the resource in `luam.json`
      changes the output directory without changing `meta.xml`.
- [ ] An `export` in a shared module produces exactly one element, and a server
      export carries no `type`.
- [ ] A project with no assets emits no file section and no file comment.
- [ ] The generated manifest for `examples/resource` matches the authored
      standard in `examples/meta.xml`, entry for entry, modulo the values that
      come from the project itself.
- [ ] `pnpm typecheck`, `pnpm build`, and `pnpm test` pass.
