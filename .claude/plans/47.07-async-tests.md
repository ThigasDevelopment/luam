# 47.07 - Cover async, await and the promise scheduler

## Objective

Lock the behaviour of the two new words, the lowering, and the merged scheduler,
including the failure modes that the hand-written promise libraries this
milestone is modelled on got wrong.

## Scope

- **In:** Unit tests across lexer, parser, checker and emitter, fixture
  snapshots, runtime tests for the promise state machine, and a microservice
  corpus exercising a promise across an event round trip.
- **Out:** Benchmarks. Scheduler throughput is a claim in 47.05, not a gate here.

## Steps

- [ ] Lexer: `async` and `await` still tokenize as identifiers outside their
      contexts, and the existing token snapshot is unchanged.
- [ ] Parser: `kinds()` and `shape()` over an async declaration, expression and
      method; `await` precedence against call, index and binary operators;
      `await` as an identifier outside an async body; `codes()` for the parse
      diagnostics.
- [ ] Checker: `local variable = await f()` binds the inner type; the four new
      diagnostics each fire on their case; `local async = 1` still compiles;
      `Promise.settle` destructures as a tuple.
- [ ] Emitter: the exact lowering string for a declaration, an expression and a
      method; variadic forwarding; `helpers(source)` returning `['promise']` for
      a bare async function and the full chain for `new Threads(...)`.
- [ ] Add a `tests/fixtures/async.luam` fixture so the token stream, AST and
      emitted Lua are snapshotted together.
- [ ] Extend the native-libraries injection matrix with `promise`, and keep the
      case where a module declaring its own `sleep` injects nothing.
- [ ] Runtime tests for the state machine: double settle is a no-op; a trailing
      nil survives; an executor that throws rejects; a spawned body that errors
      rejects and reports; `await` outside a task errors; `settle` returns the
      pair where `await` raises; an unsettled promise holds no strong reference
      to its coroutine.
- [ ] Runtime tests for the merged scheduler: `await` inside a pool job resolves;
      `pool:add` still returns the id first; the second value settles on
      completion and rejects on failure; one timer is live across two pools.
- [ ] Add a microservice corpus resource as an end-to-end case. It is the
      strongest available shape: it crosses `triggerEvent` with a promise,
      dispatches locally and synchronously on the same tick, and — before this
      milestone — wrapped its handler in `pcall`, which is exactly the Lua 5.1
      C-boundary a suspending handler cannot cross. Assert that a request
      resolves, that a failing handler rejects instead of hanging the caller
      forever, and that a request never answered is reclaimed rather than leaked.
- [ ] Review, do not blanket-update, the snapshots the new node kind churns.

## Acceptance Criteria

- [ ] `pnpm -r test` passes.
- [ ] Every failure mode listed above is covered by a test that fails against the
      current runtime.
- [ ] The corpus resource compiles, and the emitted Lua loads under Lua 5.1.
- [ ] No existing fixture snapshot changes except where the new node kind is
      genuinely present, and each such diff is reviewed in the commit.
