# 43.03 - Test the merged shared surface

> File: `.claude/plans/43.03-shared-surface-tests.md`

## Objective

Prove the shared file gained the surface, that server and client files lost
nothing, and that the build output did not move.

## Scope

- **In:** Checker fixtures, catalog coverage, CLI exit codes, emitter and manifest
  baselines, and LSP fixtures for order, labels and hover.
- **Out:** Benchmarks and any fixture that needs a live MTA server.

## Steps

- [x] Port the reported `Network` class into a fixture: no errors, one warning per
      side-restricted name, and the side named in each message.
- [x] Assert the types the merged surface carries — `localPlayer` is `Player`,
      `triggerServerEvent` keeps its arity — and that a name declared on both
      sides still resolves to its shared form.
- [x] Keep the negative side: a client-only API in a `server` file and a
      server-only API in a `client` file stay errors, with their current messages.
- [x] Assert a `shared` file importing a `client` module is still an error.
- [x] Assert `luam build` succeeds and `luam check` reports the warnings, with the
      exit codes each command promises.
- [x] Assert the generated Lua, the line map and `meta.xml` for the fixture match
      the baseline byte for byte.
- [x] Add LSP fixtures for the completion order, the side labels, the hover note,
      and the unchanged list in a server and a client file.

## Acceptance Criteria

- [x] Every assertion above has a test.
- [x] The environment, catalog-coverage, emitter, manifest and CLI suites pass,
      with only the expected severity changes updated.
