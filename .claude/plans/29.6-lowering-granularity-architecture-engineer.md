# 29.6 - Narrow canonical replacement to the lowered statement

## Objective

Replace only the statement that actually needs lowering, instead of the whole top-level statement containing it, so one rewritten line stops reformatting everything around it.

## Context

`canonicalEdits` walks top-level statements and replaces any statement that fails `canPreserveStatement`. Because the check recurses through calls, function expressions, and loop bodies, a single compound assignment or native extension buried inside a handler makes the entire handler canonical. Measured on a representative sample: an `addCommandHandler` whose body only needed annotations erased kept its authored layout exactly, while the `addEventHandler` right below it, structurally identical but containing one compound assignment, was flattened onto one line, reindented, and given a blank line the author did not write.

The same mechanism reformats a loop that contains a `continue`, so this task and 29.5 both reduce drift from different directions.

## Options Considered

| Option | Blast radius | Complexity | Decision |
|---|---|---|---|
| Keep whole-statement replacement | Entire top-level statement | None | Reject |
| Replace the innermost failing statement | The failing line only | Nested spans and indentation | Accept |
| Replace the nearest enclosing block | A block, not a file | Middle ground, still coarse | Reject |

## Scope

- **In:** Producing edits for the innermost statement that fails preservation, including statements nested inside function expressions and loop bodies, with correct indentation relative to their position.
- **Out:** Expression-level surgery inside a preserved statement. A statement is still the smallest replaceable unit.

## Steps

### T-01 - Collect nested spans

**Agent:** architecture-engineer

- [x] Record source spans for nested statements, not only top-level ones.
- [x] Ensure a nested span is available wherever `canPreserveStatement` currently returns false.

### T-02 - Descend instead of replacing

**Agent:** architecture-engineer

- [x] When a statement fails preservation but its failure comes from a nested statement, descend and emit edits for the nested statement instead.
- [x] Fall back to replacing the enclosing statement when the failure is the statement itself.
- [x] Keep edits non-overlapping, since `sourceEdits` rejects overlap.

### T-03 - Close the padding asymmetry

**Agent:** architecture-engineer

- [x] Handle the case the current padding rule ignores. `canonicalEdits` pads only when the canonical output is shorter than the authored span, so a construct whose lowering is longer silently shifts every line below it. Measured example: a class authored on one line expands to five and moves the next statement down by four.
- [x] Rule: in a development build a replacement that needs more lines than it was written on aborts source-preserving emission for the whole file, which falls back to canonical emission with its own line padding. Applied uniformly, not per construct. A minified build keeps today's shift, because its output is written on one line anyway.
- [x] Add an assertion that no edit increases the file line count, so a future construct that grows fails a test instead of drifting silently.

### T-04 - Preserve indentation and line count

**Agent:** architecture-engineer

- [x] Emit the replacement at the nested statement's own indentation.
- [x] Apply the existing blank-line padding rule to the nested span rather than the enclosing one.
- [x] Confirm the surrounding statement keeps every byte the author wrote.

## Acceptance Criteria

- [x] A handler containing one compound assignment keeps its authored layout, and only the assignment line changes.
- [x] A loop containing a `continue` keeps the layout of the statement enclosing it.
- [x] Blank lines inside an otherwise preserved statement survive.
- [x] No edit increases the file line count in a development build, for any construct, including one authored entirely on a single line.
- [x] No overlapping edits are produced for any fixture.
- [x] Release output changes only where the narrower replacement or the folded scaffolding applies, and minification erases the difference.
- [x] `pnpm typecheck` and `pnpm test` pass.
