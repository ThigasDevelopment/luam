# 15.02 - Install the luam command onto PATH

## Objective

Make `luam` runnable from anywhere on a development machine, and make the
release artifact installable, by publishing a dependency-free bundle.

## Delivered

`pnpm install:cli` bundles the CLI, writes a publishable manifest into `dist`,
installs it globally, and verifies `luam --version` runs from PATH. The
published package declares no dependencies, and the release workflow packs the
same `packages/cli/dist` that the local install uses.

A failed install reports what to fix — the npm global bin directory not being on
PATH is named with the directory, not a stack trace.

## Scope

- **In:** The `install:cli` script, the generated publishable manifest, the
  release workflow packing step, and install failure reporting.
- **Out:** Publishing to a registry, and any installer for a machine without npm.

## Acceptance Criteria

- [x] `pnpm install:cli` bundles the CLI, writes a publishable manifest into
      `dist`, installs it globally, and verifies `luam --version` runs from PATH.
- [x] The published package declares **no dependencies**. The esbuild bundle
      carries the compiler, and the manifest is generated rather than reused,
      because the workspace manifest's `workspace:*` specifiers made
      `npm install` fail with `EUNSUPPORTEDPROTOCOL` — which also made the
      release artifact uninstallable.
- [x] The release workflow packs `packages/cli/dist`, so what CI attaches to a
      release is the same thing `install:cli` installs.
- [x] A failed install says what to fix: the npm global bin directory not being
      on PATH is reported with the directory, not a stack trace.

## Decided during implementation

- **The installer shells out for npm, not for node.** Node 20+ refuses to
  `execFileSync` a `.cmd` without a shell on Windows, and passing an args array
  with `shell: true` is deprecated, so npm goes through `execSync` with a quoted
  command line while node keeps the safe array form.
- **`npm install --global <dir>` links the workspace `dist`.** On a development
  machine that is a feature: rebundling updates the installed command. It also
  means moving the repository breaks `luam` until the next install.
