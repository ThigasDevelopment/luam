# 50.04 - Split the owned console into session commands and server input

## Objective

Turn the byte pipe between the terminal and the owned MTA process into a
line-oriented channel that can tell a CLI command from a server command, without
losing anything the pipe does today.

## What exists

[server-console-input](../../packages/cli/src/server/server-console-input.ts) sets
raw mode and forwards every chunk of stdin straight to the child's stdin,
scanning only for byte `3`:

```ts
const forward = (chunk) => {
    const interruptIndex = content.indexOf(3);
    if (interruptIndex < 0) { output.write(chunk); return; }
    if (interruptIndex > 0) { output.write(content.subarray(0, interruptIndex)); }
    interrupt();
};
```

Two consequences decide this task. There is no line: a keystroke reaches MTA the
moment it is typed, so nothing can inspect a command before the server sees it.
And there is no echo in the CLI: raw mode turns off the terminal's own echo, and
what the developer sees on screen is **MTA echoing back** what it received. Buffer
the line and the screen goes silent unless the CLI echoes it itself.

## Scope

- **In:** A line buffer, a local echo, erase handling, the reserved-verb split,
  the escape for a colliding server command, and the non-TTY path.
- **Out:** What the verbs do (50.06) and how the session is opened (50.05). This
  task delivers a channel that reports a parsed session line to a callback and
  forwards everything else.

## The split

A line is a session command when its **first word** matches a reserved verb.
Anything else — including a line whose first word merely starts with one — is
forwarded verbatim. A line beginning with a space is always forwarded verbatim,
with the leading space stripped, which is the escape for a server command that
collides with a verb.

This is the cost of reserved verbs rather than a prefix: the CLI takes five names
out of a vocabulary MTA owns, and the escape is the mitigation, not a cure. Any
verb added later takes another name, which is why the list is closed at five in
50.06.

## Steps

- [ ] Rename the module to `session-console-input.ts` and give it an options
      object: the reserved verbs, the callback for a session line, and the
      interrupt. A caller that passes no verbs gets exactly today's behaviour,
      which is what `luam server` should keep passing.
- [ ] Accumulate bytes into a line buffer. Split on `\n` and `\r`, treat `\r\n`
      as one break, and dispatch each completed line separately when a paste
      delivers several at once.
- [ ] Echo typed characters to stdout while buffering, since raw mode echoes
      nothing and MTA no longer sees the keystrokes.
- [ ] On a forwarded line, erase the locally echoed line before writing it to the
      child — `\r`, spaces, `\r` — so MTA's own echo is the single record of it.
      Two echoes of one command is worse than none.
- [ ] Handle backspace (`0x7f` and `0x08`) against the buffer and the screen.
      Nothing else: no history, no arrow keys, no cursor movement. A session
      prompt that grows into a shell is a shell nobody asked for.
- [ ] Keep `Ctrl+C` exactly as it behaves today, including mid-line: interrupt,
      and discard the buffer rather than forwarding a partial line.
- [ ] When stdin is not a TTY, skip raw mode and the echo, keep the line split
      and the verb dispatch. A piped script drives the session the same way a
      person does, which is what makes 50.09 able to test it.
- [ ] Restore raw mode, the paused state and the `data` listener on close,
      exactly as the current implementation does.

## Acceptance Criteria

- [ ] `refresh` typed in a session reaches the MTA console unchanged and is
      echoed once.
- [ ] `ensure resource-a` never reaches the MTA console and arrives at the
      callback with the verb and its arguments split.
- [ ] `ensureing` and `ensure-all` are forwarded, not intercepted: the match is
      on the whole first word.
- [ ] ` ensure resource-a`, with the leading space, reaches MTA as
      `ensure resource-a`.
- [ ] A paste of three lines dispatches three times, in order, mixing session and
      server lines correctly.
- [ ] Backspace erases one character from the buffer and from the screen, and
      cannot erase past the start of the line.
- [ ] `Ctrl+C` mid-line interrupts and forwards nothing.
- [ ] With a non-TTY stdin, every case above holds except the echo.
- [ ] Constructed with no verbs, the module forwards exactly what it forwards
      today, byte for byte.
- [ ] `pnpm -r test`, `pnpm typecheck` and `pnpm conventions` pass.
