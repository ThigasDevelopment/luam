# 1.3 — Implement parser with Lua blocks

> File: `.claude/plans/1.3-parser-architecture-engineer.md`

## Objective

Deliver a parser that builds an AST for variables, functions, control flow,
and expressions using Lua block syntax (`then ... end`, `do ... end`,
`function ... end`) instead of brace blocks.

## Scope

- **In:** Statement and expression parsing, `if ... then ... end`,
  `while ... do ... end`, `for ... do ... end`, `repeat ... until`,
  `function ... end`, `return`, assignment, calls, operators.
- **Out:** Classes, interfaces, enums, and type annotations (later milestone).

## Steps

- [x] Define `Node` and statement/expression AST types.
- [x] Parse `function name(params) ... end` and anonymous `function() ... end`.
- [x] Parse `if`/`for`/`while`/`repeat` blocks with `then`/`do`/`until`
      ... `end`.
- [x] Parse expressions with precedence and compound assignment.
- [x] Report syntax diagnostics with positions.

## Acceptance Criteria

- [x] AST snapshots match for fixture programs.
- [x] An unexpected `end` or a missing `end` produces a syntax diagnostic.
- [x] All Lua blocks parse without requiring braces.
