# 45.04 - Spread unpack into the argument list it ends

> File: `.claude/plans/45.04-unpack-argument-spread.md`

## Objective

Stop reporting a false `check-argument-count` for `f(unpack(t))`, the idiom every
MTA resource uses to pass a stored position, colour or wheel state.

## Reproduction

```luam
local values = { 1, 2, 3, 4 }
local col = createColPolygon(unpack(values))
# check-argument-count: This call expects at least 8 arguments but received 1.
```

Six occurrences in the ported resource, all of them correct Lua:
`createColPolygon(unpack(data.collision))`, `tocolor(unpack(item.color))`,
`tocolor(unpack(data))`, `setVehicleWheelStates(vehicle, unpack(...))` and
`setVehicleColor(vehicle, unpack(...))` twice.

## Root Cause

The argument-count check counts AST argument nodes. Milestone 30.01 taught the
checker that a **tuple-returning call** expands as the last expression of a value
list; `unpack` is not a tuple, it is a variadic return whose arity is unknown, so
it counts as one. Lua's own rule is the same for both: the last expression of a
list contributes every value it produces.

## Scope

- **In:** The argument-count check when the last argument is a call whose return
  arity is not fixed, and the same rule in a `return` list and a multiple
  assignment.
- **Out:** Any attempt to infer the arity or the element types of the unpacked
  table. Argument **type** checking for the spread positions, which stays
  unchecked because there is nothing to check against.

## Steps

- [x] Define the rule by arity, not by name: a call in final position whose return
      is a variadic or unknown-arity descriptor suppresses the minimum-argument
      check for the positions it can fill, and the maximum check as well.
      `unpack`, `table.unpack` and any catalog function declared variadic all
      qualify, and so does a user function with no declared return.
- [x] Keep the check exact when the spread is **not** final: `f(unpack(t), 1)`
      narrows to one value in Lua, so the current count is correct there and must
      stay.
- [x] Keep checking the fixed arguments before the spread, so
      `setVehicleColor(vehicle, unpack(colors))` still checks `vehicle`.
- [x] Apply the same rule to `return f(unpack(t))` and to
      `local a, b = unpack(t)`.
- [x] Record in the diagnostics reference that a spread argument is unchecked, so
      the relaxation is a stated boundary rather than a silent hole.

## Acceptance Criteria

- [x] The six occurrences from the ported resource compile.
- [x] `f(unpack(t), 1)` still reports the count it reports today.
- [x] `setVehicleColor('not an element', unpack(colors))` still reports the first
      argument.
- [x] `local a, b = unpack(t)` types both names `any` and reports nothing.
- [x] The emitter baseline is byte identical.
