# 07.02 - Profile build and runtime helper performance

> File: `.claude/plans/07.02-performance-profiling.md`

## Objective

Profile compile time, memory, and generated runtime helper behavior on large
fixture projects, then optimize the dominant bottlenecks.

## Scope

- **In:** Build profiling, memory profiling, helper Lua performance checks,
  before/after measurements.
- **Out:** Language feature additions.

## Steps

- [x] Generate a large fixture project with many modules.
- [x] Measure initial and incremental build times.
- [x] Profile memory and cache behavior.
- [x] Profile hot runtime helpers (e.g., `string.template`, class calls).
- [x] Optimize the dominant bottleneck and re-measure.

## Acceptance Criteria

- [x] Bottleneck improvements are documented with numbers.
- [x] Incremental rebuilds are measurably faster than full rebuilds.
- [x] Runtime helpers stay Lua 5.1-compatible after optimization.
