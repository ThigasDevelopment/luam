# 47.04 - Lower async bodies onto coroutines

## Objective

Emit an async function as a coroutine driven by the promise scheduler, so
`await` and `sleep` work at any depth inside it without the author ever
constructing a pool.

## Scope

- **In:** The declaration wrap, the `await` call, helper injection at the async
  site, and the source-preserving guard.
- **Out:** Any continuation or CPS transform. The body is a real coroutine, so a
  yield crosses only Lua frames and `await` stays an ordinary call. This is what
  keeps the feature inside an emitter that has no statement buffer.

## Steps

- [ ] Wrap an async declaration's body in a closure handed to `Promise.spawn`,
      re-declaring the parameters on the inner closure and forwarding them as
      arguments rather than capturing them:
      `function f(a) return Promise.spawn(function(a) <body> end, a) end`.
- [ ] Forward `...` to an inner variadic closure for a variadic async function.
      Lua 5.1 cannot capture `...` as an upvalue, and re-declaring the parameter
      list is what makes this work without rewriting the body over an argument
      table.
- [ ] Lower an async method the same way. `self` is one more parameter.
- [ ] Emit `await e` as `Promise.await(e)`. No hoisting and no temporaries.
- [ ] Call `requireHelper(state, 'promise')` at the async site. `Promise.spawn`
      is generated and never appears in the module's references, so the reference
      scan in `compiler/src/index.ts` cannot see it.
- [ ] Return `false` from `preserve-guards` for a declaration carrying `isAsync`
      or an `await` in its body, so the canonical emitter wins for those. Source
      preservation is unchanged for every other statement.

## Acceptance Criteria

- [ ] An async declaration, expression and method each emit the wrap, and the
      emitted Lua parses under Lua 5.1.
- [ ] A variadic async function forwards its varargs, including trailing nils.
- [ ] `await` emits a plain call and the surrounding statement is otherwise
      untouched.
- [ ] A module with one async function and no named runtime global still ships
      `promise.lua`.
- [ ] Development output falls back to canonical emit for async declarations and
      is byte-identical to today for every other statement.
- [ ] The line map still resolves positions inside an async body.
