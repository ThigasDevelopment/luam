# 06.01 - Port mta-project-base framework to the language

> File: `.claude/plans/06.01-framework-port.md`

## Objective

Express `Core`, `Command`, `Event`, `Listener`, and `Threads` in the language
as a runtime framework separate from the compiler.

## Scope

- **In:** Framework classes in the language, shared/runtime separation,
  typed event and command parameters.
- **Out:** Automatic loading and CLI scaffolding.

## Steps

- [x] Port `Event`, `Listener`, `Command`, and `Core` into the language.
- [x] Type event parameters and command handlers.
- [x] Keep the framework free of compiler-only features at runtime.
- [x] Store the framework under the runtime/template area, not compiler logic.

## Acceptance Criteria

- [x] Framework compiles to Lua 5.1 and runs on MTA.
- [x] Classes use runtime helpers, not compile-only features.
- [x] Framework remains separate from the compiler packages.
