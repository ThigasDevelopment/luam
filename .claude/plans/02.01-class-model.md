# 02.01 - Add class model and semantics

> File: `.claude/plans/02.01-class-model.md`

## Objective

Extend the binder and checker to understand `class`, `extends`, `implements`,
fields, constructors, methods, and defaults.

## Scope

- **In:** Class AST, field/method registration, constructor resolution,
  inheritance resolution, `implements` contract validation, duplicate-class errors.
- **Out:** Class emission and runtime injection.

## Steps

- [x] Extend AST with `ClassDecl`, `MethodDecl`, and field declarations.
- [x] Register classes and resolve `extends` inheritance chains.
- [x] Resolve `self:super(...)` calls against the parent.
- [x] Validate `implements` contracts statically.
- [x] Detect duplicate class definitions.

## Acceptance Criteria

- [x] Class fixtures with inheritance bind correctly.
- [x] A missing parent class is a diagnostic.
- [x] A class failing its interface contract is a diagnostic.
