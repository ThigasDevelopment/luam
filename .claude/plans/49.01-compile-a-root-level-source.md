# 49.01 - Compile a source file that sits at the project root

## Objective

Make `index.luam` next to `.luam.manifest` a buildable resource: a `.luam` file
directly in the project root that no `sources` pattern matches enters the build
with no assigned side, so its `#!` directive decides and `shared` applies when it
declares none.

## Scope

- **In:** `discoverSources`, a depth-0 listing of the project root, and the
  `ProjectFile` those files produce.
- **Out:** The `luam dev` watcher, which is 49.02, and the diagnostic for a
  `.luam` file in an unmatched subdirectory, which is 49.03. Also out: changing
  `DEFAULT_SOURCE_MAPPING` or the scaffolded manifest — the root is picked up
  regardless of what `sources` says, so neither has to learn a new pattern.

## Why the root and not every unmatched file

[project-layout](../../docs/en/guide/project-layout.md) states the rule this
milestone must not break: a file no `sources` pattern and no `assets` mapping
names is not part of the build, and nothing is copied by accident. A directory
tree is exactly where accidents live — a vendored copy, an `examples/` folder, a
scratch file two levels down. The project root is one directory, it holds the
manifest, and a `.luam` file put there was put there on purpose. That is the one
place worth reading without a pattern.

The side falls out of code that already exists.
[resolveEnvironment](../../packages/compiler/src/environment/environment.ts)
returns `fromDirective ?? assigned ?? DEFAULT_ENVIRONMENT`, and its
`env-path-directive-conflict` warning fires only when a mapping or a path already
assigned a side. Leaving `environment` unset on the `ProjectFile` — not setting
it to `shared` — is therefore the whole feature: the directive wins silently,
and a file with no directive is `shared`. The language server already resolves an
open root file this way, because `resolver.side` returns null for it. This task
closes the gap where the editor accepts a file the build refuses.

## Steps

- [ ] Add `listRootFiles(root, excluded)` to
      [project-files](../../packages/cli/src/build/project-files.ts): one
      `readdirSync` with `withFileTypes`, no recursion, directories skipped,
      `isExcludedPath` honoured, names returned sorted. Leave `listProjectFiles`
      untouched; the pattern walk keeps its own entry point.
- [ ] In [source-discovery](../../packages/cli/src/build/source-discovery.ts),
      after the pattern walk, take the root entries that end in
      `SOURCE_EXTENSION`, are not `isTestPath`, and for which
      `resolver.resolve(path).matches.length === 0`. A root file a pattern
      already names is not touched here: it keeps its mapped side and its
      `config-source-side-conflict` check.
- [ ] Read each through the existing `readSource`, so a read failure stays
      `build-source-unreadable`, and push `{ path, source }` with `environment`
      left undefined. Do not assign `shared`; assigning it is what would make a
      `#!client` root file warn about a conflict it does not have.
- [ ] Leave the `matched` set alone. It feeds `checkLiterals`, which answers a
      different question — whether a literal `sources` entry exists — and a root
      file was never listed there.
- [ ] Keep the final sort, and let the existing `files.length === 0` guard see
      the root files, so a flat project stops reporting `config-no-sources`.
- [ ] Confirm nothing downstream assumes `src/`: `outputPath` only swaps the
      extension, so `index.luam` writes `index.lua` at the resource root in the
      mirrored layout and joins the shared bundle in the bundled one, and
      `meta.xml` reads the side off the compiled module.

## Acceptance Criteria

- [ ] A project holding the manifest `luam init` writes plus `index.luam` at the
      root builds. `meta.xml` declares the script as `shared` and the output is
      `index.lua`.
- [ ] `#!client` on the first line of that file makes it a client script, with no
      `env-path-directive-conflict` warning. `#!server` behaves the same.
- [ ] A root file a pattern does name — `shared = { '*.luam' }` — keeps the
      mapping's side, and a `#!client` on it still warns exactly as today.
- [ ] `index.test.luam` at the root is not built, and a root `.d.luam` is treated
      as the declaration file it already is.
- [ ] `tools/helper.luam` in an unmatched subdirectory is still not built.
- [ ] The root pickup costs one `readdirSync`; no recursive walk is added to a
      build that succeeds.
- [ ] `pnpm -r test`, `pnpm lint` and `pnpm typecheck` pass.
