# 18.02 - Emit a source line map for every module

> File: `.claude/plans/18.02-emitter-line-map.md`

## Objective

Make a generated Lua line resolvable to the `.luam` line and the enclosing
symbol that produced it, closing a gap that exists in the current tree layout
and that bundling would otherwise deepen.

## Scope

- **In:** Line bookkeeping in the emitter, the map on `EmitResult` and
  `CompiledModule`, its participation in the project cache, and the map's
  format.
- **Out:** Column precision, the bundle-level map and the map file (20.3), and
  every consumer of the map (20.3).

## Options Considered

| Option | Precision | Output cost | Decision |
|---|---|---|---|
| Pad generated output to the source line | Exact until a construct emits more lines than it occupies | Inflates every file, fights ADR-010 | Reject |
| Comment each statement with its origin | Exact and readable without tooling | Inflates every shipped file | Reject |
| Record a map at emit time | Exact at statement granularity | None in the output | Accept |

## Behavior Contract

The emitter records a pair whenever the source line behind the output changes,
producing `lines: SourceLineMapping[]`, where a mapping is a generated line, the
`.luam` line it came from, and optionally the name of the enclosing function,
method, or class body. Generated lines between two pairs belong to the earlier
pair.

The map is module-local and 1-based on both sides. It is produced regardless of
the output layout and regardless of whether anything consumes it.

A module reused from the project cache returns the map it was compiled with. A
changed module invalidates its map with its code.

The generated Lua is byte-identical to what the emitter produces today. The map
is additional data, never a change to the output.

## Steps

- [x] Add `sourceLine` tracking to `EmitState`: a current source line, a current
      enclosing symbol name, and an append path that records a pair when either
      changes.
- [x] Route statement emission through that path so every statement records the
      position of the AST node it came from, including statements nested in
      blocks, function bodies, class bodies, and lowered constructs.
- [x] Set the enclosing symbol when entering a function expression, a function
      declaration, a class method, and a generated accessor, and restore it on
      exit.
- [x] Add `lines` to `EmitResult` and `CompiledModule`, and carry it through
      `collectScripts` onto `ResourceScript`.
- [x] Store and restore `lines` in `project-cache` alongside the module code,
      keyed by the same fingerprint.
- [x] Define `SourceLineMapping` and the sparse encoding in one place in the
      compiler, so 20.3 and the tests share a single definition.
- [ ] Snapshot the map for the existing fixtures so drift is visible in review.

## Acceptance Criteria

- [x] `pnpm typecheck` and `pnpm test` pass.
- [x] Every existing emitter and fixture snapshot of generated Lua is unchanged.
- [ ] For `control-flow.luam`, generated line 2 maps to source line 4, and every
      subsequent statement maps to the line it was authored on.
- [x] A class method body maps to its authored lines and carries the enclosing
      symbol name.
- [x] A decorator-generated accessor maps to the field that produced it.
- [x] A module reused from the cache reports the same map as a module compiled
      from scratch.
- [ ] The map for a module with no blank lines and no lowered construct is the
      identity, and is encoded as a single pair.
