# 01.01 - Scaffold pnpm workspace and compiler package

> File: `.claude/plans/01.01-scaffold-workspace.md`

## Objective

Create the pnpm workspace with the `compiler` package so lexer, parser,
checker, and emitter work can begin on a solid foundation.

## Scope

- **In:** Workspace root config, TypeScript strict config, Vitest setup, `compiler` package entry points.
- **Out:** No language features yet; no CLI or LSP packages.

## Steps

- [x] Create `package.json` at root with `pnpm` workspace and `workspaces` entries.
- [x] Create `tsconfig.base.json` with strict mode and path aliases.
- [x] Create `packages/compiler` with `package.json` and `src/index.ts`.
- [x] Add Vitest config and a smoke test that compiles an empty source string.

## Acceptance Criteria

- [x] `pnpm install` resolves the workspace.
- [x] `pnpm --filter compiler test` passes the smoke test.
- [x] Strict TypeScript passes `tsc --noEmit`.
