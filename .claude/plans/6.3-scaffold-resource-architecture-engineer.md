# 6.3 — Add resource scaffold command

> File: `.claude/plans/6.3-scaffold-resource-architecture-engineer.md`

## Objective

Let the CLI scaffold a new resource project with the framework, source
folders, and configuration ready to build.

## Scope

- **In:** `scaffold`/`init` command, folder structure, framework files,
  starter config and manifest, example handler.
- **Out:** Publishing the template as a package.

## Steps

- [x] Implement the scaffold command.
- [x] Generate `src/server`, `src/client`, `src/shared`, and framework files.
- [x] Generate starter configuration and example handler.
- [x] Verify the scaffold builds and runs.

## Acceptance Criteria

- [x] `scaffold` creates a buildable project.
- [x] The generated resource runs on MTA with auto-loading.
- [x] The scaffold uses the shared runtime framework.
