# 12.01 - Unify CLI output with a color and symbol vocabulary

> File: `.claude/plans/12.01-output-style.md`
> Foundation for the milestone. Every later task renders through the layer this
> task introduces, so it lands first.

## Objective

Give every message the CLI prints one vocabulary — a colour per severity, a
symbol per phase, one place that decides whether either is safe to emit — so
that an error never looks like an informational line again.

## Scope

- **In:** The style module, capability detection, the reporter boundary that
  sits between commands and `Logger`, and the migration of the existing
  messages onto it.
- **Out:** Phase instrumentation (12.2), the progress renderer (12.3),
  diagnostic layout (12.4).

## Steps

- [x] Add a style module owning the palette and the symbols. Nothing else in the
      repository writes an escape sequence.
- [x] Define the severity vocabulary: error, warning, success, and muted detail.
      Colour carries meaning, never decoration.
- [x] Define the phase symbols — discovery, compile, assembly, manifest, write,
      sync, restart — plus the success, warning, and failure markers.
- [x] Detect capability once per process: colour is off when the stream is not a
      TTY, when `NO_COLOR` is set, or when `--no-color` is passed. Emoji degrade
      to ASCII markers under the same rule, so a redirected log stays readable.
- [x] Keep `Logger` as the plain sink it is today. The reporter decides what a
      line looks like and hands `Logger` a finished string, so the memory logger
      the CLI tests use keeps capturing plain text.
- [x] Keep `info` on stdout and `warn`/`error` on stderr.
- [x] Migrate every existing message, and fix the unpluralised `Wrote 1 files`
      while passing through.
- [x] Keep CLI output in English, matching every message the CLI prints today.

## Acceptance Criteria

- [x] With a TTY, an error line is red and a warning line is yellow; with the
      output piped, both are plain text identical to today's format.
- [x] `NO_COLOR=1` and `--no-color` each suppress colour and emoji.
- [x] No escape sequence is produced outside the style module.
- [x] The existing CLI tests pass without being taught about colour.
- [x] Counts are pluralised everywhere, files included.
