# 1.5 — Implement Lua 5.1 emitter and extensions

> File: `.claude/plans/1.5-emitter-architecture-engineer.md`

## Objective

Deliver an emitter that lowers typed Lua to Lua 5.1, including compound
assignment, template strings, and native object extensions. Lua blocks emit
directly — no brace-to-`end` translation is needed.

## Scope

- **In:** Lua 5.1 output for statements/expressions, `if ... then ... end`,
  `for ... do ... end`, `repeat ... until`, `function ... end`, compound
  assignment, `string.template`, `table.count`/`string.trim` rewrites, runtime
  helper requirement tracking.
- **Out:** Class and enum emission (later milestone).

## Steps

- [x] Implement emitter for statements and expressions.
- [x] Emit `if ... then ... end`, `for ... do ... end`, `repeat ... until`,
      and `function ... end` blocks directly.
- [x] Lower `+=`, `-=`, `..=` to standard assignment.
- [x] Lower backtick template strings to `string.template` with context tables.
- [x] Rewrite native property extensions (`items.count`, `name.trim`).
- [x] Record which runtime helpers the emitted code requires.

## Acceptance Criteria

- [x] Fixture snapshots match expected Lua 5.1 output.
- [x] Template string output passes the root variable context table.
- [x] Extension usage marks the matching runtime helper as required.
