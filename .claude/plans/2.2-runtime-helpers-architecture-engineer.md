# 2.2 — Add runtime helper modules

> File: `.claude/plans/2.2-runtime-helpers-architecture-engineer.md`

## Objective

Add Lua 5.1 runtime helpers (`class.lua`, `threads.lua`) to the `runtime`
package and define injection rules.

## Scope

- **In:** `class.lua` and `threads.lua` from lua-class/mta-threads, runtime
  package layout, dependency requirement mapping.
- **Out:** Manifest wiring (later milestone).

## Steps

- [x] Create `packages/runtime` with `class.lua` and `threads.lua`.
- [x] Define a map of language feature to required runtime helper.
- [x] Document which helpers may be copied into a resource.

## Acceptance Criteria

- [x] Runtime helpers are standalone Lua 5.1 files.
- [x] The feature-to-helper map covers classes and enums.
- [x] Helpers are not bundled into the compiler itself.
