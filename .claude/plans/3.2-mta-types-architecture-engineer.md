# 3.2 — Add MTA API type catalogs

> File: `.claude/plans/3.2-mta-types-architecture-engineer.md`

## Objective

Provide typed declarations for Lua, MTA server/client/shared APIs, and
language extensions scoped by environment in `mta-types`.

## Scope

- **In:** Lua standard functions, MTA server functions/events, MTA client
  functions/events, shared globals (`root`, `getElementByID`), typed
  `table.*`/`string.*` extensions, `Player`/`Vehicle`/`Element` types.
- **Out:** LSP-specific features (later milestone).

## Steps

- [x] Create `packages/mta-types` with environment-scoped declaration modules.
- [x] Type Lua standard library globals.
- [x] Type MTA server and client function signatures and events.
- [x] Type language extension helpers and core element types.

## Acceptance Criteria

- [x] `outputChatBox` is server-only; `dxDrawText` is client-only.
- [x] `root`, `source`, and element functions resolve with types.
- [x] Extension helpers (`table.count`, `string.template`) are typed.
