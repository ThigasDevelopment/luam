# 19.01 - Define the CLI command contract and migration boundary

> File: `.claude/plans/19.01-cli-command-contract.md`

## Objective

Define a stable command, option, output, and exit-code contract before replacing
the hand-written CLI parser.

## Scope

- **In:** A command-option matrix, a decision record for Commander and production
  minification, and the public compatibility rules for all current commands.
- **Out:** Rewriting command implementations, changing the Luam language, or
  changing compiler and MTA resource semantics.

## Steps

- [x] Inventory `build`, `check`, `dev`, `doctor`, `ensure`, `init`, `setup`,
      and `trace`, including operands, defaults, required project configuration,
      streams, and exit codes.
- [x] Define each option at command scope instead of accepting unrelated global
      options: `--name` and `--force` for `init`; `--yes` for `setup`; `--map`
      for `trace`; layout, map, watch, and offline options where applicable.
- [x] Define global options: `--cwd`, `--config` where a project can be loaded,
      `--no-color`, `--help`, and `--version`.
- [x] Record an ADR that evaluates the existing parser, Commander, and an
      alternative parser against correctness, maintainability, compatibility,
      and testability.
- [x] Record the production-output contract: `build` minifies scripts; `ensure`
      and `dev` retain readable tree output; no identifier renaming is part of
      this milestone.
- [x] Define the source-map limitation for a one-line artifact: a line-only MTA
      stack trace cannot identify the original line and `trace` must not report a
      false mapping.

## Acceptance Criteria

- [x] Every current command and option has one documented owner and default.
- [x] Invalid command-option combinations have a documented usage error.
- [x] The contract preserves exit code `0` for success, `1` for operational or
      diagnostic failure, and `2` for invalid usage or configuration.
- [x] The ADR explicitly rejects regex-based Lua minification and identifier
      renaming for the initial production mode.
