# 24.10 - Expose a safe class metamethod subset

## Objective

Permit explicitly modeled Lua metamethods that do not bypass class identity, member lookup, or constructor invariants.

## Decision Boundary

`__index`, `__newindex`, and `__call` remain blocked unless a future ADR replaces the class object model. The initial candidate set is `__tostring`, comparisons, length, concatenation, and arithmetic operators supported by Lua 5.1.

## Scope

- **In:** Allowlist ADR, signatures, inheritance, operator checking, runtime installation, diagnostics, completion, tests, and security review.
- **Out:** Arbitrary metatable mutation, dynamic metamethod names, blocked lookup/call hooks, and Lua versions newer than 5.1.

## Steps

### T-01 - Threat-model each candidate

**Agent:** security-engineer

- [ ] Evaluate class identity, lookup bypass, recursion, denial-of-service, inconsistent equality, and MTA userdata interactions.
- [ ] Accept each metamethod individually with its Lua 5.1 arity and return contract.

### T-02 - Define source and type semantics

**Agent:** architecture-engineer

- [ ] Compare dedicated syntax, reserved method names, and decorators; choose the least ambiguous form.
- [ ] Map binary and unary operators to candidate methods and define inheritance and override compatibility.
- [ ] Reject blocked or misspelled metamethods before emit.

### T-03 - Extend runtime safely

**Agent:** architecture-engineer

- [ ] Install accepted methods without exposing the underlying metatable or replacing class-owned `__index`, `__newindex`, or `__call` behavior.
- [ ] Guard accidental recursive dispatch where the runtime can detect it cheaply.

### T-04 - Verify runtime behavior

**Agent:** test-engineer

- [ ] Test every accepted signature and operator, inheritance, invalid returns, blocked names, and existing getter/setter behavior.
- [ ] Run generated behavior under a Lua 5.1-compatible runtime when available.

## Acceptance Criteria

- [ ] Every exposed metamethod has an accepted threat-model entry and exact type signature.
- [ ] `__index`, `__newindex`, and `__call` remain impossible to override through source or runtime APIs.
- [ ] Existing class construction, accessors, identity, and method dispatch remain unchanged.
- [ ] Generated classes remain valid Lua 5.1.
