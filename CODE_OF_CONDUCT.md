# Code of Conduct

## The standard

This project adopts the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. It is linked rather than copied so that the text you read
is the current one, and it applies in full.

## What it means here

In practice, in a project this size, it comes down to a short list.

- Discuss the change, not the person who wrote it. A review is about code.
- Assume the other person is trying to help. A misunderstanding is more likely
  than bad faith, in either direction.
- English is the working language of this repository, and most people writing it
  here are not writing their first language. Imperfect English is not a defect.
- Harassment, personal attacks, and unwelcome attention are not acceptable in an
  issue, a pull request, a review, a commit message, or a private message that
  started here.
- The maintainer's decisions about scope are final and are not personal. "Not
  planned" is an answer, and it is usually accompanied by a reason in writing.

## Scope

It applies to every space this project uses — issues, pull requests, reviews,
discussions, and commit history — and to any place someone represents the
project publicly.

## Reporting

Report a concern privately to the maintainer through their
[GitHub profile](https://github.com/ThigasDevelopment). Conduct that violates
GitHub's own terms can also be reported to
[GitHub Support](https://support.github.com/contact/report-abuse), which can act
independently of this project.

Reports are handled privately. The maintainer may warn, remove content, or block
an account, in proportion to what happened. This is a single-maintainer project;
there is no committee and no promised response time.
